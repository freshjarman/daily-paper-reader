## 摘要
时空点过程（STPPs）对连续时间和空间中的事件数据建模，应用于移动性、流行病学和公共安全。最近的神经STPPs涵盖了表达强度模型、条件密度模型、连续时间潜在动态、归一化流空间解码器以及基于分数的生成机制。然而，由于实现方式在预处理、坐标标准化、数据划分、似然约定和评估协议上存在差异，比较仍然不可靠。我们提出了SEAHORSE，一个用于可复现STPP实验的统一框架。SEAHORSE通过一个通用的编码-演化-解码接口形式化神经STPPs，并在统一的可执行基准协议下训练、调优和评估每个模型族，同时报告原始坐标似然。这不仅实现了公平比较，更重要的是实现了受控的诊断研究。我们将SEAHORSE与HawkesNest（一个合成压力测试套件）结合，并表明增加事件模式复杂性会揭示每个模型族的归纳偏置，使一些模型性能急剧下降，而另一些保持稳定。代码：https://github.com/YahyaAalaila/seahorse。

## Abstract
Spatiotemporal point processes (STPPs) model event data in continuous time and space, with applications in mobility, epidemiology, and public safety. Recent neural STPPs span expressive intensity models, conditional density models, continuous-time latent dynamics, normalizing-flow spatial decoders, and score-based generative mechanisms. Yet comparison remains fragile because implementations differ in preprocessing, coordinate normalization, splits, likelihood conventions, and evaluation protocols. We present SEAHORSE, a unified framework for reproducible STPP experimentation. SEAHORSE formalizes neural STPPs through a common encode-evolve-decode interface and trains, tunes, and evaluates every model family under a single executable benchmark protocol with raw-coordinate likelihood reporting. This enables fair comparisons but, more importantly, controlled diagnostic studies. We pair SEAHORSE with HawkesNest, a synthetic stress-test suite, and show that increasing event-pattern complexity exposes each family's inductive bias, degrading some models sharply and leaving others stable. Code: https://github.com/YahyaAalaila/seahorse.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：时空点过程（Spatiotemporal Point Process, STPP）模型在多个领域（如地震学、流行病学、城市规划）中用于建模连续时空中的事件序列。近年来神经STPP模型快速发展，但不同模型的比较存在严重障碍：实现方式在预处理（坐标标准化、数据归一化）、数据划分、似然计算方法、评估协议等方面高度不一致，导致结果无法直接复现和公平比较。
- **整体含义**：作者旨在建立一个统一的基准框架，使得各种STPP模型（包括强度模型、密度模型、连续时间潜在动态、归一化流、分数生成模型等）能够在相同的预处理、训练、评估协议下进行公平对比，并通过可控合成压力测试揭示不同模型的归纳偏置。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：提出 **SEAHORSE** 框架，通过一个共同的 **编码-演化-解码（Encode-Evolve-Decode）** 接口统一所有神经STPP模型，并引入一个可执行的基准协议，强制所有模型使用相同的数据处理、坐标变换和原始坐标似然报告。
- **关键技术细节**：
  - **统一模型分解**：每个STPP模型被分解为三个组件：
    - **历史编码器（History Encoder）**：从过去事件序列提取表示（如RNN、Transformer、集合编码器）。
    - **状态演化（State Evolution）**：描述编码状态如何随时间变化（如分段常数、神经常微分方程）。
    - **解码器（Decoder）**：产生下一个事件的预测分布（如混合模型、归一化流、整数网络、分数网络）。
  - **基准协议**：
    - 数据集、事件顺序、划分（train/val/test）在原始坐标下固定。
    - 模型可自行估计归一化、支持域等，但只能基于训练集，且变换存储于运行元数据中。
    - 所有评估指标（如负对数似然 NLL）均在原始坐标下报告，若模型在变换空间计算似然，则施加对数雅可比校正。
    - 支持多种执行模式：`fit`（单次训练）、`tune`（超参数搜索）、`bench`（多模型多数据集多种子基准）、`evaluate`（后训练诊断）。
  - **合成压力测试套件 HawkesNest**：生成具有已知真实强度的受控时空事件，通过改变时空耦合程度（L0–L3 递进）来诊断模型偏置。
- **公式/算法流程（文字说明）**：每个模型遵循自回归条件分布：给定历史 $H_{t_i}$，编码器得到隐状态，演化器更新到当前时间，解码器输出下一个事件的分布（$p(t, x, y | H_t)$）。训练时优化各自的目标（精确似然、数值似然、变分下界、分数匹配等），但基准测试时统一以原始坐标 NLL 作为主要指标。

## 3. 实验设计
- **数据集**：
  - **真实数据集**（3 个核心）：Citibike（纽约自行车出行开始点，2019年4-8月）、USGS Earthquakes（日本1990-2020年震级≥2.5）、COVID-19（新泽西县级病例）。另有10个额外数据集存储于仓库但未用于主要对比（如Uber、犯罪、火灾、社交签到等）。
  - **合成数据集**：HawkesNest 纠缠套件，4个难度级别（L0 最容易，L3 最难），逐渐增强时空耦合。
- **Benchmark 协议**：固定 70/10/20 时间划分，3个种子（seed 1,2,3）。所有模型在相同事件序列上训练后，在原始坐标下计算测试 NLL，并使用坐标校正。
- **对比方法**（共约15种预设）：
  - 神经STPP：AutoSTPP、DeepSTPP、NSMPP、NJSDE、Jump-CNF、Attn-CNF。
  - 生成模型：SMASH、DSTPP。
  - 时间基线（带空间头）：RMTPP、THP。
  - 经典分解基线：Poisson、Hawkes、自纠正（SC-Hawkes），每种搭配三种空间头（高斯混合 GMM、连续归一化流 CNF、时变 CNF TvCNF）。
- **评估指标**：主指标为每事件测试 NLL；辅助指标包括 temporal CRPS（时间预测）、intensity correlation（强度表面恢复，仅合成套件）、rollout coherence（自回归生成稳定性）、PIT 校准误差等。

## 6. 论文的主要结论与发现
- **无统一胜者**：模型在真实数据集上的排名依赖于数据集（Attn-CNF 在 COVID 和 Citibike 上最好，DeepSTPP 在地震最好）。
- **经典模型仍有竞争力**：Hawkes + 时变 CNF 空间头在 Citibike 上接近神经模型，表明自激发机制加灵活解码器仍有效。
- **可控暴露偏置**：
  - 在纠缠套件中，NSMPP 因建模联合强度加性内核始终获得最佳 NLL，但 temporal CRPS 和 intensity correlation 并不占优（其似然优势并不意味着更好的强度恢复）。
  - AutoSTPP 和 DeepSTPP 对强纠缠 L3 较敏感（学习曲线表现出固定的性能差距或需要更多预算）。
  - 生成模型（SMASH、DSTPP）在 NLL 上整体落后。
- **学习动态揭示差异**：收敛路径、最佳检查点位置、最终与最佳 NLL 差距等暴露模型优化行为。
- **诊断比单个分数更重要**：控制测试可以揭示哪些模型在何种条件下退化，为未来模型设计提供指导。

## 7. 优点
- **统一性**：将不同类型的 STPP 模型通过 encode-evolve-decode 接口统一，降低比较时的实现歧义。
- **原始坐标似然报告**：通过坐标校正消除因不同归一化带来的 scale 差异，使报表可比。
- **诊断导向**：引入 HawkesNest 受控套件，支持从 NLL、预测精度、强度恢复、自回归稳定性等多个维度剖析模型。
- **开源与可扩展**：代码公开，提供 CLI 与 Python API，易于添加新模型或新数据集，并自动记录元数据（目标、空间、支持能力等）。
- **执行模式丰富**：包括训练、调参、批量基准、后训练评估，标准化了实验流程。
- **元数据完备**：每个运行记录目标、似然类型、坐标空间、评估能力、种子等，支持审计与复现。

## 8. 不足与局限
- **实证覆盖有限**：主要只用了 3 个真实 2D 数据集，尽管仓库有 13 个但未在正文深入分析，可能影响结论的泛化性。
- **昂贵模型不够充分**：部分连续时间和流模型（如 Jump-CNF）因计算成本高，完成种子数少（有些仅 1 种子），且未统一调参，可能引入偏差。

- **未处理协变量或标记**：框架设定限于时空位置，未扩展至带协变量或多类事件的高维标记 STPP。
