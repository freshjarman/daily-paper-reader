## 摘要
下一个活动预测有助于服务导向型流程在延迟、异常或服务级别风险发生之前预判后续步骤。现有方法大多假设经典的单案例事件日志，而实际服务流程往往涉及多个类型业务对象共享的事件。对象中心事件日志（OCELs）捕获了此类交互，但当前的预测器仍存在局限性。基于扁平化的方法丢失了跨对象上下文，而基于原生OCEL图的方法通过成对关系编码多对象事件。现有模型也未能联合捕获事件驱动的对象状态变化、事件间时序以及全局执行模式。我们提出EHHN，一种面向对象中心的下一个活动预测的事件驱动异构超图网络。EHHN将每个预测前缀表示为异构超图，其中事件-对象超边绑定保留的共同参与对象，生命周期超边将主要对象的已观察生命周期事件分组。基于该表示，EHHN采用双流架构：微观空间流建模事件驱动的对象状态演化，宏观演化流通过检索全局原型捕获时间动态。两个流融合后用于预测下一个活动。在四个公开OCEL基准数据集上与九种基线方法的实验表明，EHHN在所有数据集上均达到最佳准确率和宏F1分数，相比最强基线分别提升最多8.1和12.4个百分点。与最强的原生OCEL图基线相比，EHHN还将峰值GPU内存降低了最多24倍。代码开源在https://github.com/chenkaitao1112/EHHN。

## Abstract
Next activity prediction helps service-oriented processes anticipate upcoming steps before delays, exceptions, or service-level risks occur. Most existing methods assume classical single-case event logs, whereas real service processes often involve events shared by multiple typed business objects. Object-centric event logs (OCELs) capture such interactions, but current predictors remain limited. Flattening-based approaches lose cross-object context, and native OCEL graph-based approaches encode multi-object events through pairwise relations. Existing models also do not jointly capture event-driven object state changes, inter-event timing, and global execution patterns. We propose EHHN, an Event-driven Heterogeneous Hypergraph Network for object-centric next activity prediction. EHHN represents each prediction prefix as a heterogeneous hypergraph, where event--object hyperedges bind retained co-participating objects and a lifecycle hyperedge groups the primary object's observed lifecycle events. Based on this representation, EHHN uses a dual-stream architecture in which a micro-spatial stream models event-driven object-state evolution and a macro-evolution stream captures temporal dynamics using retrieved global prototypes. The two streams are fused to predict the next activity. Experiments on four public OCEL benchmarks against nine baselines show that EHHN achieves the best accuracy and macro F1-score on all datasets, with improvements of up to 8.1 and 12.4 percentage points over the strongest baselines. Compared with the strongest OCEL-native graph baseline, EHHN also reduces peak GPU memory by up to 24 times. Code is available at https://github.com/chenkaitao1112/EHHN.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：面向服务流程的下一个活动预测中，现有方法大多基于经典单案例事件日志，无法处理事件由多个类型业务对象共享的真实场景。对象中心事件日志（OCEL）记录事件与所有涉及对象，但已有预测方法存在四个主要局限：
  - 扁平化方法（如选择单对象类型）丢失跨对象上下文。
  - 原生 OCEL 图方法通过成对边编码多对象事件，削弱了事件与所有参与对象的联合绑定。
  - 未区分事件（瞬态触发器）与对象（持久状态）的不对称角色。
  - 缺少事件间时序和全局执行模式的联合建模。
- **研究目标**：提出一种保留多对象事件语义、联合捕获事件驱动状态演化、时序动态和全局模式的预测模型。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将每个预测前缀表示为异构超图，并采用双流架构编码局部状态演化和全局时序模态。
- **关键技术**：
  1. **异构超图构建**：
     - 四层节点：主要对象（primary object）、其已观察生命周期事件、共同参与的辅助对象、辅助对象的历史上下文事件（2-hop 扩展）。
     - 超边类型：
       - 事件-对象超边：每个事件与参与对象绑定，保留联合多对象参与。
       - 生命周期超边：主要对象的所有已观察生命周期事件。
     - 节点特征：对象属性（min-max 数值、one-hot 类别）；事件属性 + 循环时间编码 + 相对于生命周期起点的 log 尺度时间特征。
  2. **微空间流（Micro-Spatial Stream）**——建模局部事件驱动对象状态演化：
     - JEST（联合事件驱动状态转移）：
       - 对每个事件，聚合其参与对象的当前表示得到上下文向量 `c_e`；
       - 结合事件表示生成更新信号 `i_e = MLP([h_e ∥ c_e])`；
       - 对每个对象，累加其关联事件的信号并通过 GRU 更新状态。
     - LCSE（生命周期约束状态演化）：聚合主要对象生命周期事件表示形成生命周期轮廓 `p_opri`，并用 GRU 更新主要对象状态，辅助对象保持 JEST 结果。
     - HIE（异构交互编码器）：通过两个残差 UniGAT 层对齐事件和对象表示到共享空间。
     - 门控读出：融合主要对象表示与平均池化的最后三个事件表示得到 `h_micro`。
  3. **宏进化流（Macro-Evolution Stream）**——捕获时序和全局模式：
     - TASE（时间感知状态演化）：对主要对象的生命周期事件序列使用带对数时间衰减偏置的 Transformer 编码器，偏置 `B_time[i,j] = −|w|·log(1+Δ_t_ij) + b`，其中 Δ_t_ij 为标准化后的累积时间差。
     - 全局原型记忆（Global Prototype Memory）：
       - 维护可学习原型矩阵 `P ∈ R^{K×D}`，查询向量由 h_micro 和 h_traj 拼接后投影并 L2 归一化。
       - 计算余弦相似度，保留 Top-k_p 并 softmax 得到权重，加权原型作为全局上下文 `c_global`。
       - 通过特征调制（FiLM）对 TASE 输出 `h_traj` 进行调制：`γ = 1 + α tanh(MLP_γ(c_global))`，`β = α tanh(MLP_β(c_global))`，初始化为零以实现逐步学习。
  4. **融合与预测**：`h_final = h_micro + (γ⊙h_traj + β)`，然后经两层 MLP 和 softmax 分类。
  5. **训练损失**：交叉熵（主任务）+ Smooth L1 辅助时间预测损失（线性预热）+ 正交性正则化 `L_div = ∥P̃ P̃^T − I_K∥_F^2`（防止原型坍缩）。

## 7. 优点
- **创新表示**：异构超图同时保留多对象事件联合绑定和生命周期结构，避免扁平化或成对分解的信息损失。
- **不对称建模**：将事件视为瞬态信号源、对象视为持久状态，通过 JEST 和 LCSE 准确捕获事件驱动状态转移。
- **双流互补**：微观空间流侧重局部结构，宏观进化流通过时间衰减注意力和全局原型注入时序与全局知识。
- **高效内存**：通过 2-hop 边界剪枝和超图稀疏结构，在大规模数据上显著降低 GPU 内存需求。
- **可解释性**：原型记忆激活热图显示原型对应特定业务阶段，增强模型透明度。
- **鲁棒性**：噪声下性能稳定，适用于真实日志缺陷场景。
- **公平验证**：在多个复杂基准上，与多种基线进行充分对比，并严格遵循标准分割和超参数调优。

## 8. 不足与局限
- **宏进化流增益有限**：消融显示单独宏流（TRANS）性能差，且全模型相对仅微空间流（SPATIAL）的提升在部分数据集上较小，尤其是 Intermediate 上近似持平。
- **推理延迟较高**：每样本延迟（10~38 ms）远高于 Flat-LSTM（~1 ms），对实时要求高的服务可能需优化。
- **原型数选择依赖数据集**：虽敏感性分析显示波动较小，但最佳 K 仍需调参（如 P2P 需 K=64）。
- **未考虑流式更新**：当前模型为离线批量设置，未验证在持续到达的 OCEL 流中的适应能力。
- **验证范围**：仅在四个公开数据集上评估，缺少工业级真实日志验证，且数据集规模相对较小（最大 39 万事件）。
