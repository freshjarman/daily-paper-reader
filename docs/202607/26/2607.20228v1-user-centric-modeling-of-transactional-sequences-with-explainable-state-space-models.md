## 摘要
我们提出了一种混合方法，用于对交易事件序列进行以用户为中心的建模，该方法结合了对比表示学习（CoLES）和状态空间模型（SSM）。虽然对比方法能生成高质量的压缩用户表示，但现有的编码器（如RNN和Transformer）分别存在梯度消失或二次复杂度问题。Mamba作为一种选择性SSM，能高效处理长距离依赖，但在个性化用户分析方面尚未被充分探索。我们研究了两种集成策略：（1）使用CoLES嵌入初始化Mamba隐藏状态，（2）将投影后的CoLES嵌入作为前缀标记添加到输入序列之前。两种方法都从第一步起就为模型提供了信息丰富的用户先验。在三个公开数据集（用于多类别年龄组预测的Age、用于多标签产品获取的MBD、用于二元购买预测的Taobao）上的实验表明，与单独的Mamba和带线性分类器的CoLES相比，混合模型取得了持续改进，且混合模型收敛速度比普通SSM基线快2-3倍。通过离散化步骤图和积分梯度进行的可解释性分析揭示了在行为丰富数据集上的选择性事件过滤，并识别了信息量最大的交易特征。

## Abstract
We propose a hybrid approach for user-centric modeling of transactional event sequences that combines contrastive representation learning (CoLES) with State Space Models (SSMs). While contrastive methods yield high-quality compressed user representations, existing encoders -- RNNs and Transformers -- suffer from vanishing gradients or quadratic complexity, respectively. Mamba, a selective SSM, efficiently handles long-range dependencies but remains underexplored for personalized user analysis. We investigate two integration strategies: (1)~initializing the Mamba hidden state with a CoLES embedding, and (2)~prepending the projected CoLES embedding as a prefix token to the input sequence. Both approaches supply the model with an informative user prior from the first step. Experiments on three public datasets -- Age (multiclass age-group prediction), MBD (multi-label product acquisition), and Taobao (binary purchase prediction) -- demonstrate consistent improvements over standalone Mamba and CoLES with a linear classifier, with the hybrid models converging 2--3$\times$ faster than the plain SSM baseline. Explainability analysis via discretization-step maps and Integrated Gradients reveals selective event filtering on behavior-rich datasets and identifies the most informative transaction features.

- **背景**：现代数字服务中，每一次用户交互（购买、页面浏览、金融交易）都被记录为带时间戳的事件序列，称为事务性事件序列。准确建模这些序列对欺诈检测、信用评分、流失预测和个性化推荐至关重要。
- **核心问题**：现有序列编码器存在根本性局限——RNN（GRU/LSTM）受限于顺序处理和梯度消失，难以捕捉长距离依赖；Transformer通过自注意力解决了长程依赖，但复杂度为 \(O(L^2)\)，对于银行业务序列（平均881个事件/用户，总事件数达2100万或1.56亿）计算开销巨大。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：将对比表示学习（CoLES）与Mamba SSM混合，通过注入用户先验来提升序列建模能力。CoLES以自监督方式训练，生成稳定的用户嵌入（用户轮廓），而Mamba作为下游编码器处理完整序列。
- **两种集成策略**：
    1. **隐藏状态初始化（Hidden-state initialization）**：将CoLES用户嵌入通过两层非线性投影（\(h_0 = W_2 \sigma(W_1 e_{\text{CoLES}})\)）作为Mamba第一层的初始隐藏状态 \(h_0\)（原本为零向量）。后续层接收前一层输出状态。
    2. **前缀拼接（Prefix concatenation）**：将CoLES嵌入通过线性投影 \(P\) 转换为与输入token相同维度的向量，然后作为额外上下文token拼接到输入序列前面：\(\tilde{X} = [P e_{\text{CoLES}}; X]\)。Mamba可以在后续位置学习如何条件化于该用户先验。
- **CoLES训练**：在全部数据（训练+测试集，无标签泄露）上自监督训练100K步，冻结权重。
- **特征预处理**：数值特征经 \(\log(1+|x|)\cdot\operatorname{sign}(x)\) 变换、每序列z-score归一化、线性投影；类别特征映射到嵌入表；时间戳编码为差分 \(\delta t_i = t_i - t_{i-1}\) 并类似处理；所有特征向量拼接成每个事件的输入token \(\mathbf{x}_t \in \mathbb{R}^{d_{\text{model}}}\)。
- **训练协议**：AdamW优化器，早停（patience=3，最大100 epoch），在验证集上监测。

## 6. 主要结论与发现
- **性能提升**：两种混合方法在所有三个数据集上一致优于Plain Mamba和CoLES+线性分类器。最大绝对提升在Age（+3.2个百分点）和MBD（+2.6个百分点），Taobao提升较小（+0.7个百分点）。
- **收敛更快**：混合模型在2-3 epoch即达到峰值验证性能，而Plain Mamba需要6 epoch，提升2-3倍。
- **CoLES+线性分类器表现最差**，说明序列上下文对预测很重要，CoLES嵌入更适合作先验而非独立预测器。
- **可解释性**：离散化步长显示，在Taobao（电商）数据上模型学会选择性过滤低意图事件（如浏览）并放大高意图事件（如加入购物车、购买）；而在Age和MBD（银行）数据上\(\Delta_t\)均匀分布在[0.75,1.0]之间，无选择性过滤。积分梯度表明：货币特征在MBD中占主导（重要性0.154），Age中三个特征重要性几乎均匀，Taobao中项目标识符和行为类型重要性接近。
- **冷启动**：对于没有预计算嵌入的用户，替换为零向量，混合模型退化为普通Mamba，提供自然的冷启动回退方案。

## 7. 优点
- **方法设计巧妙**：将对比学习获得的用户级先验注入SSM，既利用了CoLES的表示质量，又保留了Mamba高效处理长序列的能力。两种注入策略（初始状态 vs. 前缀）简单有效。
- **收敛加速**：混合模型收敛速度提升2-3倍，具有实际工业部署价值。
- **可解释性分析深入**：使用两种互补XAI技术（离散化步长图和积分梯度），揭示了模型在不同类型数据上的行为差异（选择性过滤 vs. 均匀处理），增强了模型可信度。
