## 摘要
我们提出了一种基于发现频繁闭合嵌入子有向无环图（DAG）的新方法，用于挖掘时空事件数据中的模式。在我们的方法中，事件实例表示为由事件类型标记的节点，而边则捕获时空跟随关系。我们正式定义了所考虑的模式类别，并提供了将重点放在闭合子DAG上作为紧凑且无冗余的重复交互模式表示的理由。我们实现了用于挖掘此类模式的DigDag算法，并通过实验将其效率与两种相关方法进行了比较：使用SLEUTH算法的传播模式挖掘和使用CSTPM算法的级联时空模式挖掘。实验结果表明，在可比的参数设置下，我们的方法效率显著更高。最后，我们对选定的发现模式进行了定性分析。

## Abstract
We propose a novel approach to mine patterns in spatio-temporal event data based on discovering frequent closed embedded sub-Directed Acyclic Graphs (DAGs). In our method, event instances are represented as nodes labelled by event types, while edges capture spatio-temporal following relationships. We formally define the considered class of patterns and provide the rationale for focusing on closed sub-DAGs as compact and non-redundant representations of recurring interaction patterns. We implement the DigDag algorithm for mining such patterns and experimentally compare its efficiency with two related approaches: propagation pattern mining using the SLEUTH algorithm and Cascading Spatio-Temporal Pattern mining using the CSTPM algorithm. The experimental results demonstrate that our approach is substantially more efficient while operating under comparable parameter settings. Finally, we present a qualitative analysis of selected discovered patterns.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：时空事件数据（如城市犯罪事件）蕴含丰富的交互模式，现有方法如传播模式挖掘（基于子树）或级联时空模式挖掘（CSTP）存在效率低下或表示冗余的问题。例如，基于树的表示无法捕获一个事件由多个前驱事件共同诱发的情况（如事件D需要B和C同时发生才能触发），而DAG结构能更自然地建模此类“多对一”的时空跟随关系。
- **核心问题**：如何高效地、非冗余地从一组时空事件实例中挖掘出频繁出现的交互结构，并输出紧凑且信息完整的模式集合。
- **整体含义**：提出一种基于频繁闭合嵌入子DAG的模式发现框架，旨在替代现有的子树或级联模式，在保证信息量的前提下大幅提升挖掘效率，为犯罪事件分析等场景提供可解释的支撑工具。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**  
  - 将每个事件实例表示为带标签（事件类型）的节点，基于用户给定的空间半径 \(R\) 和时间窗口 \(T\) 定义“时空跟随关系” ≺：实例 \(i_2\) 跟随 \(i_1\) 当且仅当空间距离 ≤ \(R\) 且时间差在 \((0, T]\) 内。  
  - 由此构建一组有向无环图（DAG），每个DAG包含若干实例及边（跟随关系）。  
  - **嵌入子DAG**定义：子图 \(G'\) 中任意边 \((u,v)\) 在原始DAG中存在从 \(u\) 到 \(v\) 的有向路径（不一定直接相连）。  
  - **频繁**：该子DAG出现在总DAG集合中的比例 ≥ 用户给定阈值 \(minSup\)。  
  - **闭合**：不存在另一个频繁嵌入子DAG \(G''\) 使得本子图是 \(G''\) 的真子图且两者支持度相同。闭合性消除了冗余，仅保留最紧凑的代表性模式。

- **关键技术细节与算法流程**  
  1. **预处理**：根据输入事件数据集 \(D\)、参数 \(R\) 和 \(T\)，使用Haversine公式计算空间距离，构建所有DAG。  
  2. **DigDag算法内部步骤**：  
     - 将每个DAG分解为一组“tile”（瓦片）：以每个非叶节点为根，包含该节点及其所有后代（descendants）构成的子图。  
     - 将每个tile转换为事务（transaction），其中项为事件类型标签的集合。  
     - 利用频繁闭合项集挖掘（closed frequent itemset mining）算法，在瓦片集上寻找频繁项集，再映射回子DAG结构。  
     - 输出所有满足闭合条件的频繁嵌入子DAG。  
  - 作者未对DigDag原始算法进行修改，直接使用其作为内部组件，实现基于Python的networkx库。
