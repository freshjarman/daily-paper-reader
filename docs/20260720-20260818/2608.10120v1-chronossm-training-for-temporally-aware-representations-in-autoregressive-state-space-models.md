## 摘要
现代序列模型，从Transformer到状态空间模型，已在多个领域实现了强大的生成建模，但它们的典型训练目标是预测发生什么，而将何时发生视为次要问题。在事件带有显式时间信息的数据挖掘场景中，这种分离会限制时间推理、异常检测以及事件时间顺序的忠实重建。一种常见策略是将时间视为辅助信号，使用仅为事件预测而学习的表示来训练一个独立的时间模型。然而，这种两阶段方法隐含地假设为事件预测优化的表示已经包含了足够的时间结构。我们引入了ChronoSSM，一种自回归状态空间模型（SSM），它使用共享主干联合建模事件和时间戳，并通过结合词元与时间生成目标进行训练。我们将联合方案（时间监督更新主干）与两阶段方案（仅使用冻结的事件表示来学习时间）进行比较。在涵盖密集和部分时间戳监督的四个领域中，联合训练始终使到达间隔信息更容易从冻结表示中恢复，而不会在整体内容生成质量上造成系统性下降。我们的结果表明，时间监督能够产生更具时间信息量的表示，而不会实质性降低自回归事件建模的性能。

## Abstract
Modern sequence models, from Transformers to State Space Models, have enabled powerful generative modeling across diverse domains, yet they are typically trained to predict what happens while treating when it happens as a secondary concern. In data-mining settings where events are associated with explicit timing information, this separation can limit temporal reasoning, anomaly detection, and faithful reconstruction of event chronology. A common strategy is to treat timing as an auxiliary signal, training a separate timing model using representations learned solely for event prediction. However, this two-stage approach implicitly assumes that representations optimized for event prediction already contain sufficient temporal structure.   We introduce ChronoSSM, an autoregressive State Space Model (SSM) that jointly models events and timestamps with a shared backbone trained using combined token and temporal generation objectives. We compare the joint regime, where temporal supervision updates the backbone, with the two-stage regime, where timing is learned only using the frozen event representations. Across four domains spanning dense and partial timestamp supervision, joint training consistently makes inter-arrival information more recoverable from frozen representations without any systematic degradation in content-generation quality overall. Our results show that temporal supervision can produce more temporally informative representations without materially degrading autoregressive event modeling.

## 二、方法论

### 2.1 ChronoSSM 模型框架

- **共享主干**：以 Mamba2（选择性状态空间模型）为主要骨干，可替换为任意因果自回归骨干（附录中验证了 GPT-2 实例化）。主干对输入序列 X_k 产生逐词元隐藏表示 h_k = Backbone_θ(X_k)。
- **联合分布分解**：将下一事件及其到达间隔的联合分布按链式法则分解为两个因子：
  - p(x_{k+1} | X_k)：词元预测因子，由线性映射 + softmax 实现；
  - p(Δt_{k+1} | x_{k+1}, X_k)：时间预测因子，由时间头实现。
- **时间表示设计**：到达间隔是连续两个词元之间的差值，因此其预测表示取相邻隐藏状态之差：r_{k+1} = Δh_{k+1} = h_{k+1} − h_k，与时间目标 Δt_{k+1} = t_{k+1} − t_k 形成"差值对差值"的对应结构。

### 2.2 训练目标

- 负对数似然分解为词元损失（交叉熵）与时间损失（固定方差的 log-normal 密度负对数似然）之和。
- 实际训练采用加权目标：L = L_tok + λ_τ · L_time，其中 λ_τ 控制时间监督的相对贡献。
- 时间目标使用 log(1 + Δt/s) 变换（s 为数据集特定的时间尺度），以压缩长间隔并容纳零间隔（避免 log(0) 未定义）。时间头输出经 softplus 非线性得到非负点估计。

### 2.3 两种训练方案

- **联合训练（Joint）**：主干与两个预测头同时优化，时间损失的梯度通过 Δh 回传更新主干参数，鼓励相邻隐藏状态的变化携带到达间隔信息。
- **两阶段训练（Two-Stage）**：第一阶段只用词元损失训练主干和词元头；第二阶段冻结主干，仅训练时间头。作为受控基线，用于隔离"时间监督能否塑造主干"这一变量的效应。

### 2.4 推理

自回归生成：先由词元头预测下一词元，处理后计算 Δh，再由时间头预测间隔并累加时间戳。

## 六、主要结论与发现

1. **RQ1（时间可恢复性）得到肯定回答**：在所有四个领域，Joint 训练相比 Two-Stage 均获得更高的 TCS 和探针 R²、更低的探针 MAE。效果幅度因领域而异：网络流量提升最显著（TCS 从 0.147→0.622，R² 从 0.190→0.394），时间知识图谱提升较小但方向一致。
2. **RQ2（质量退化）得到否定回答**：没发现系统性退化。BPI2018 上两种方案生成质量完全相同；MIMIC-IV 上 Joint 在边际分布指标上有轻微退化但高频事件覆盖率不变；网络流量和时间知识图谱上 Joint 反而在内容生成质量上明显更优。
3. **时间监督可以增强表示的时间信息性而不损害事件建模**：时间梯度可以重塑共享主干的表征结构，"时间-语义权衡"并非必然。
4. **辅助实验**：GiantMIDI 中 Joint 大幅提升重叠面积分数（均值 OA 从 0.016→0.172），但 TCS 保持不变（负值），探针指标略微偏好 Joint。
5. **逐层几何分析**：不同领域的表示变化模式差异很大（BPI2018 全局变化温和、MIMIC-IV 局部邻域结构变化大而全局不变、网络流量全局局部均大幅重组、知识图谱中间层发散后收敛），不存在统一的单一机制解释。

## 七、优点

- **问题定位精准**：清晰区分"联合建模时间"与"两阶段事后拟合时间"两种训练范式，提出明确且可操作的研究问题（RQ1/RQ2），并以受控实验直接回答。
- **时间表示的差值设计**：将时间目标 Δt 与表示 Δh 建立一一对应，直觉清晰、计算轻量，避免了拼接表示导致维度翻倍的问题。
- **框架通用性**：不绑定特定骨干架构（SSM/GPT-2 均可），扩展性良好。
- **实验严谨**：受控对比变量单一；多领域覆盖；多维度评价（可恢复性诊断+生成质量+保留损失+几何分析）；外部基线被合理定位为描述性参考。
- **透明度与诚实性**：如实报告 GPT-2 骨干的不一致结果、时间知识图谱上 Two-Stage 的验证时间损失更低、替代时间表示不成立等不利于主叙事的结果，增强可信度。
- **实际开销友好**：Joint 训练在同等 epochs 下训练时间相当甚至更短，且无需单独时间头训练阶段。

## 八、不足与局限

- **架构迁移性有限**：主结论基于 Mamba2 骨干；GPT-2 扩展实验中，部分领域 Joint 的恢复性优势消失甚至反转，生成质量对比也更混杂。论文解释为 Mamba2 的循环状态动态可能更适合时间转换表示，但未做严谨的架构效应隔离（容量、优化超参数等混杂因素未控制），因此结论的普适性受限。
- **时间生成质量的评估缺口**：RQ2 的评价协议主要针对事件内容（领域标准的生成质量指标），缺少对"自由生成时间戳分布保真度"的系统评估。论文自己也承认，保留验证集上的时间损失只是条件点预测误差的粗略度量，并不能替代对真实生成时间分布的比较。
- **λ_τ 选择缺乏系统性**：权重选择依据"与词元损失量级匹配"这一启发式规则；敏感性分析仅覆盖两个部分时间戳域，密集时间戳域未做扫描。
- **外部基线的描述性局限**：基线与 ChronoSSM 在架构、目标、时间表示、生成流程等方面均不同，无法用于严格比较；且部分基线（如 RE-Net）生成质量显著更高但时间可恢复性差，说明"生成质量"与"时间可恢复性"是不同维度，但论文未能深入解释这一分野的机制。
