## 摘要
不规则多变量时间序列广泛应用于医疗监测、人类活动识别和环境感知等场景。其核心挑战源于异步观测、非均匀采样间隔，以及时间模式本身携带关键动态信息这一事实。现有方法要么依赖基于离散化的预处理（如插值、填补或聚合），这会破坏底层连续时间语义，要么通过基于ODE的框架采用连续时间建模，但这类方法通常需要专用架构，并因数值求解器而产生大量计算开销。为解决上述问题，我们提出WrapFlow，一种用于不规则时间序列预测的连续时间建模框架。在输入侧，WrapFlow引入连续时间分词（Continuous-Time Tokenization），直接编码原始观测事件，并通过感知间隔的令牌显式建模长未观测区间。随后，生成的连续时间令牌由标准Transformer主干处理，以捕获长程时间依赖。在输出侧，我们开发了一种免模拟的训练范式用于残差流匹配（Residual Flow Matching），该范式在基础预测周围学习条件残差向量场，同时避免训练过程中的数值求解器模拟和反向传播。这一设计仅需在推理时使用少量固定展开步骤即可实现高质量连续预测。在多个真实世界数据集上的大量实验表明，WrapFlow达到了最先进的性能。

## Abstract
Irregular multivariate time series are widely encountered in applications such as healthcare monitoring, human activity recognition, and environmental sensing. Their core challenges stem from asynchronous observations, non-uniform sampling intervals, and the fact that temporal patterns themselves carry critical dynamic information. Existing approaches either rely on discretization-based preprocessing (e.g., interpolation, imputation, or aggregation), which disrupts the underlying continuous-time semantics, or adopt continuous-time modeling via ODE-based frameworks, which typically require specialized architectures and incur substantial computational overhead due to numerical solvers. To address these limitations, we propose WrapFlow, a continuous-time modeling framework for irregular time series forecasting. On the input side, WrapFlow introduces Continuous-Time Tokenization, which directly encodes raw observation events and explicitly models long unobserved intervals via gap-aware tokens. The resulting continuous-time tokens are then processed by a standard Transformer backbone to capture long-range temporal dependencies. On the output side, we develop a simulation-free training paradigm for Residual Flow Matching, which learns conditional residual vector fields around base predictions while avoiding numerical-solver simulation and backpropagation during training. This design enables high-quality continuous forecasting using only a small number of fixed rollout steps at inference. Extensive experiments on multiple real-world datasets demonstrate that WrapFlow achieves state-of-the-art performance.

## 1. 论文的核心问题与整体含义

不规则多变量时间序列（IMTS）在医疗监控、人类活动识别和环境感知等场景中广泛存在。其核心挑战来自三个方面：**异步观测**（不同变量在不同时刻被记录）、**非均匀采样间隔**（同一变量内部采样间隔不固定）以及**时间模式本身携带关键动态信息**（如密集观测可能意味着状态快速变化，长间隔可能意味着系统稳定）。

现有方法存在两类问题：
- **离散化预处理方法**（插值、填补、聚合）：简单但会不可逆地破坏底层连续时间语义；
- **基于 ODE 的连续时间方法**：需要专用动态架构和数值求解器，计算成本高、优化复杂。

因此，论文提出一个核心研究问题：**如何高效且有效地捕获 IMTS 的连续时间动态？** 为此，作者提出 **WrapFlow**——一个统一的连续时间建模框架，在不依赖离散化和数值求解器模拟的前提下，实现高质量的不规则时间序列预测。

## 2. 论文提出的方法论

### 2.1 整体架构

WrapFlow 由三个互补组件构成：输入侧连续时间分词（Continuous-Time Tokenization）+ 标准 Transformer 主干 + 输出侧残差流匹配（Residual Flow Matching）增强。

### 2.2 输入侧：连续时间分词（Continuous-Time Tokenization）

将每个原始观测事件作为基本单元，编码为三类语义不同的令牌：

- **Event Token**：对普通观测事件，编码值为 `g_v(x_nk) + e_var + φ_abs(t) + φ_rel(Δt) + e_event_type`，融合变量身份、绝对时间、相对间隔和事件类型信息；
- **GAP-aware Event Token**：当同一变量距离上一可见事件的时间超过阈值 τ_gap 时，添加可学习的 GAP 类型嵌入，显式建模长未观测区间的语义；
- **Mask GAP Token**：训练时随机掩蔽一段连续历史区间，用值无关的令牌（去除值投影项）代替原始事件，用于恢复监督，使模型能区分自然长间隔与人为掩蔽片段。

每个变量按时间顺序排列令牌序列，并填充到批内最大长度（padding 位置在注意力中掩蔽）。

### 2.3 Transformer 主干与查询解码器

- 主干：标准掩蔽注意力 Transformer，将每个变量的令牌序列编码为上下文记忆 H_n；
- 查询解码器：构建两类值无关查询——未来查询（预测目标时间戳）和掩蔽历史查询（训练时恢复历史），通过交叉注意力从对应变量的记忆流中检索时间特定上下文。

### 2.4 输出侧：残差流匹配（Residual Flow Matching）

**核心思想**：模型先产生确定性基础预测（anchor），再用流匹配学习从该基础预测到真实值的残差修正轨迹。

- **训练阶段（免模拟）**：对于未来分支和掩蔽历史分支，在 [0,1] 上采样流时间 τ，线性插值噪声与目标残差，构造目标速度场，直接回归向量场。损失函数为 `L = L_dir + λ_f·L_f + λ_h·L_h`（直接预测损失 + 未来流匹配损失 + 历史流匹配损失），避免了数值求解器模拟与 ODE 反向传播；
- **推理阶段**：从零残差状态出发，通过少量固定步数（如 Euler 积分）ODE rollout 得到残差修正，加到基础预测上得到最终预测。

### 2.5 关键公式

- 线性插值路径：`x_τ = (1-τ)x_0 + τ·r`，目标速度 `v_τ = r - x_0`；
- 未来查询构造：`q = e_var + φ_abs(s) + φ_rel(Δt) + e_future_type`；
- 推理预测：`ŷ = x̄ + r_1`，其中 `r_1` 为 ODE 终端残差。

1. **性能领先**：WrapFlow 在大部分评估指标上取得最佳结果。相比第二名 APN，在关键数据集上 MSE 最大提升约 3%、MAE 最大提升约 5.7%（USHCN 上 MSE 0.1401 vs 0.1590，提升约 11.9%）。此外，MIMIC 上 MSE 0.4218 vs 0.4292，PhysioNet 上 0.3047 vs 0.3093。在 HumanActivity 上 MSE 略逊于 APN（0.0449 vs 0.0421）但 MAE 更优，表明方法在不同特征的数据集上各有取舍；
2. **跨领域稳定性**：在临床、生物力学和气候数据上均表现一致，说明连续时间建模框架捕获了广泛适用的时间模式；
3. **消融验证**：连续时间分词是最关键的组件（去除后性能下降最大），流匹配增强提供基础预测之外的补充修正，交叉注意力、GAP 令牌和相对位置编码均有贡献；
4. **参数规律**：最佳隐藏维度与数据集固有复杂度相关，并非越大越好；编码器深度大多偏浅（1–4 层）；间隙阈值需适中，过小过度强调、过大会忽略有效长间隔。

## 7. 优点

- **双重连续时间建模**：输入侧直接编码原始事件与间隔信息，输出侧学习连续残差向量场，两端都保持连续时间语义，设计逻辑自洽；
- **免模拟训练**：流匹配分支在训练时直接回归目标向量场，避免了 ODE 数值求解器的模拟和反向传播，训练成本显著降低，推理仅需极少量rollout步骤；
- **GAP 感知设计**：显式区分自然长间隔和训练掩蔽区间，增强了模型对不规则的时序语义的理解能力，是一个精巧的细节设计；
- **主干模块复用性**：采用标准 Transformer 而非专用 ODE 架构，降低了工程实现门槛，与主流模型基础设施兼容；
- **自监督辅助任务**：掩蔽历史恢复分支提供额外监督信号，增强残差向量场对历史上下文的利用，且推理时无需该分支；
- **公平的实验协议**：采用 5 个随机种子报告均值±标准差，遵循 TFB/TAB 公平性协议，不耍 "Drop Last" 技巧。

## 8. 不足与局限

1. **计算效率证据缺失**：论文声称"高效"，但未提供与 ODE 类基线（NeuralFlows、CRU）和强基线（APN、KAFNet）在训练时间、推理延迟、参数量上的直接定量对比；
2. **跨变量交互建模有限**：每个变量的令牌独立编码并单独做交叉注意力，尽管 Transformer 内部有一定全局交互，但缺乏如 tPatchGNN、Raindrop 中显式的图/变量依赖建模机制，可能限制具有强跨变量相关性的场景性能；
3. **基础预测误差的累计风险**：流匹配学习的是相对于基础预测的残差，若基础预测（anchor）存在系统偏差，残差匹配的上限会受制约——虽然 detach 操作分离了梯度，但没讨论这一耦合关系的理论保障；
4. **生成形式受限**：输出的是点预测而非概率分布，虽然流匹配天然支持采样，但论文并未利用这一特性做不确定性量化；与概率预测基线（NeuralFlows、CRU）的对比主要在点预测精度上；
5. **缺乏理论分析**：未提供残差流匹配的收敛性、最优传输路径性质等理论分析；
6. **附录信息披露有限**：数据集预处理细节和实际运行日志不完整；HumanActivity 数据集上 MSE 不优于 APN，但论文未对此给出具体分析，值得探讨；
7. **应用边界未讨论**：未讨论该方法在极高维变量（如 >1000 变量）、超长序列或在线学习/流式场景中的扩展性问题。
