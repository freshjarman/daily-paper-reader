## 摘要
事件日志出现在广泛的现实世界过程中，不仅记录事件活动和时间戳，还捕获多模态上下文信息。现有的事件序列模型，包括许多时间点过程方法，主要对事件活动和时间戳建模，而忽略了异构上下文，例如与单个事件和整个轨迹相关的数值测量、类别属性、文本描述和元数据。在本文中，我们提出通用多模态Traceformer（UMT），一个将异构过程上下文纳入下一事件预测的统一框架。UMT建立在Transformer骨干之上，引入了一个通用特征编码器，将多种特征类型映射到共享表示空间，并在事件级和轨迹级处理上下文信息。UMT进一步开发了逐事件Perceiver模块，该模块动态地对上下文特征进行加权，并将它们自适应地整合到事件token表示中。为了适应到达间隔时间的重尾且可能多峰的分布，UMT在多个时间尺度上表示每个间隔，并联合预测相应的尺度特定量。在13个真实世界事件日志上的实验表明，UMT在下一事件活动预测和时间预测上均优于现有方法。

## Abstract
Event logs arise in a wide range of real-world processes, capturing not only event activities and timestamps but also multi-modal contextual information. Existing event-sequence models, including many temporal point process approaches, primarily model event activities and timestamps while overlooking heterogeneous context, such as numerical measurements, categorical attributes, textual descriptions, and metadata associated with individual events and entire traces. In this paper, we propose Universal Multi-Modal Traceformer (UMT), a unified framework for incorporating heterogeneous process context into next-event prediction. Built on a Transformer backbone, UMT introduces a universal feature encoder that maps diverse feature types into a shared representation space and handles contextual information at both the event and trace levels. UMT further develops a per-event Perceiver module that dynamically weights contextual features and adaptively integrates them into event-token representations. To accommodate the heavy-tailed and potentially multi-modal distribution of inter-arrival times, UMT represents each interval at multiple temporal scales and jointly predicts the corresponding scale-specific quantities. Experiments on 13 real-world event logs show that UMT improves both next-event activity and time prediction over existing approaches.

# 论文总结：Universal Multi-Modal Traceformer（UMT）

## 1. 核心问题与整体含义
- **研究背景**：事件日志广泛存在于电商、IT服务台、医疗、能源、交通等事件驱动系统中。日志不仅包含事件活动与时间戳，还包含数值测量、类别属性、文本描述、元数据等异构上下文。
- **核心问题**：现有事件序列模型主要分为两类：
  - 时间点过程（TPP）：多建模活动与时间，较少纳入结构化协变量；
  - 预测性过程监控（PPM）：多基于前缀预测下一活动，常依赖特定日志的列选择、固定 schema 或离散化，且常只预测活动或时间中的一部分。
- **整体含义**：论文希望提出一个统一架构，能够无需针对新日志做专门特征工程，直接吸收事件级与轨迹级的多模态异构上下文，并联合预测下一事件的活动与到达间隔时间。

## 2. 方法论
- **总体框架**：UMT 由四部分组成：
  1. 通用多模态特征编码器；
  2. 逐事件 Perceiver 融合模块；
  3. 因果 Transformer 骨干；
  4. 多尺度到达间隔时间预测头。
- **问题形式化**：
  - 一条轨迹表示为 \(\Gamma=(c,((a_t,\Delta_t,x_t))_{t=1}^T)\)，其中 \(c\) 为轨迹级上下文，\(a_t\) 为活动，\(\Delta_t\) 为到达间隔，\(x_t\) 为事件级上下文。
  - 给定前缀 \(\Gamma_{\le t}\)，预测下一活动 \(a_{t+1}\) 与下一到达间隔 \(\Delta_{t+1}\)。
- **通用特征编码器**：
  - 对每个异构字段 \(u_{t,j}\)，使用模态特定编码器 \(g_j\) 映射到共享维度 \(d\)：\(f_{t,j}=g_j(u_{t,j})\)。
  - 类别字段用可学习 embedding，并为缺失值和未见类别设置专门条目；
  - 数值字段结合缺失指示符，经 MLP 编码；
  - 文本字段用轻量预训练语言模型池化后投影；
  - 编码后保留为独立 feature token，而非过早拼接或聚合。
- **逐事件 Perceiver 融合**：
  - 对每个事件，用活动 embedding 与时间 embedding 构造查询：
    \(q_t=W_q[e_a(a_t);e_\Delta(\Delta_t)]+b_q\)。
  - 查询对所有上下文 feature token 做 cross-attention：
    \(\alpha_t=\mathrm{softmax}(K_t q_t^\top/\sqrt{d_q})\)，\(s_t=\alpha_t^\top V_t\)。
  - 融合上下文再与活动、时间 embedding 拼接，形成事件 token：
    \(z_t=W_z[s_t;e_a(a_t);e_\Delta(\Delta_t)]+b_z\)。
  - 优点：支持不同数量与类型字段；每个事件动态加权；注意力随字段数线性增长。
- **因果 Transformer 建模**：
  - 对事件 token 加位置编码，输入 L 层因果 Transformer；
  - 因果掩码保证 \(h_t\) 只依赖前缀；
  - 下一活动分布为 \(p(a_{t+1}|\Gamma_{\le t})=\mathrm{softmax}(W_a h_t+b_a)\)。
- **多尺度到达间隔建模**：
  - 将 \(\Delta_t\) 分解为天、小时、分钟：
    \(\Delta_t=D_t\cdot 86400+H_t\cdot 3600+M_t\cdot 60\)。
  - 天组件为非负、过离散计数，使用 Negative Binomial 分布：
    \((\mu_t,r_t)=\mathrm{softplus}(f_d(h_t))\)，\(D_{t+1}\sim NB(\mu_t,r_t)\)。
  - 小时和分钟组件有周期性，用单位圆上的角度表示：
    \(u_{h,t+1}=[\cos(2\pi H_{t+1}/24),\sin(...)]\)，分钟同理。
  - 预测头输出二维向量并归一化，用 cosine 距离作为损失，避免边界不连续。
- **学习目标**：
  - 活动损失为交叉熵：\(L_{a,t}=-\log p(a_{t+1}|\Gamma_{\le t})\)。
  - 时间损失为 NB 负对数似然加小时、分钟 cosine 损失：
    \(L_{\Delta,t}=-\log p_{NB}+\lambda_h(1-\hat u_h^\top u_h)+\lambda_m(1-\hat u_m^\top u_m)\)。
  - 总损失在轨迹有效预测位置上平均。

## 3. 实验设计
- **数据集**：13 个公开真实事件日志，覆盖业务流程、IT 事件、能源、医疗、食品安全、交通等领域。
  - 8 个 BPI Challenge 日志：BPI-2012、BPI-2013、BPI-2015-1、BPI-2015-2、BPI-2017-Off、BPI-2020-Dom、BPI-2020-Int、BPI-2020-Req；
  - 5 个其他日志：National-Grid、IT-Incidents、Medical-Appts、Chicago-Food、Train-Delays。
- **划分方式**：
  - 按 case 开始时间排序，最近 15% 作为测试集；
  - 剩余 85% 再按 85/15 随机分为训练与验证，seed 42；
  - 按 case 划分避免事件级泄漏，符合“用过去 case 预测未来 case”的部署场景；
  - 超过训练 case 长度 95 分位的序列左截断，绝对上限 150 个事件。
- **评价指标**：
  - 下一活动预测：Accuracy；
  - 到达间隔预测：MAE，单位按数据集为小时、天或分钟；
  - 所有实验重复 5 个随机种子，报告均值与标准差。
- **对比方法**：
  - Neural Hawkes；
  - Transformer Hawkes；
  - IFTPP；
  - GRU-based marked TPP；
  - 自身模型的 feature-stripped 变体 UMT†；
  - GRU 的 feature-stripped 变体 GRU†。
- **消融与深入分析**：
  - 特征模态消融：限制为仅类别、仅数值、仅文本、仅 case 级、仅 event 级、无上下文；
  - 上下文宽度扩展：用与标签无关的合成干扰列将上下文扩展到 100 列，比较 additive fusion 与 Perceiver；
  - 时间头替换：LogNormal、Mixture of LogNormal、Poisson day count 等；
  - 模型容量与超参数敏感性：宽度、深度、学习率、权重衰减；
  - 注意力分析：Perceiver cross-attention 与互信息排序、因果干预；Transformer 自注意力模式。

## 6. 主要结论与发现
- **活动预测**：UMT 在 13 个数据集中 11 个取得最高下一活动准确率；在 BPI-2013、National-Grid、Medical-Appts 上超过最强基线 7–21 个百分点。
- **时间预测**：UMT 在 13 个数据集中 9 个取得最低 MAE；在 Medical-Appts、Chicago-Food、BPI-2013、BPI-2017-Off 等跨多个数量级的数据集上相对提升明显，部分 MAE 降低 27%–40%。
- **多模态特征价值**：在元数据丰富的数据集上，特征编码器贡献显著，例如 BPI-2013 提升约 16 个准确率点，Chicago-Food 提升约 34 个点，Train-Delays 提升约 5 个点；但在近马尔可夫或特征无益的数据集上，上下文可能中性甚至有害。
- **多尺度时间头**：相比 LogNormal 等标准头，平均降低约 12% MAE；Poisson day count 明显更差，说明负二项过离散建模关键。
- **Perceiver 融合鲁棒性**：将上下文扩展到 100 列合成干扰列时，additive fusion 最多损失 13.5 个准确率点，而 Perceiver 变体最多损失约 3.6 个点，说明事件条件动态加权能抵抗无关特征。
- **注意力可解释性**：Perceiver 注意力与字段对下一活动的互信息正相关；模型会忽略已作为输入的活动名称等冗余字段；因果干预显示高注意力字段通常也是预测最敏感字段。
- **超参敏感性**：性能对宽度、深度、学习率、权重衰减不敏感，除 BPI-2015 等约 400 活动类型的数据集外，参考配置位于性能平台而非精细调优点。

## 7. 优点
- **统一多模态编码**：将数值、类别、文本字段统一映射到共享 token 空间，并处理缺失值与未见类别，减少对新日志的专门特征工程。
- **事件条件动态融合**：Perceiver 根据当前事件的活动与时间自适应加权上下文，支持不同 schema 和字段数量，且计算复杂度随字段数线性增长。
- **多尺度时间建模**：将重尾到达间隔分解为过离散天计数与周期内小时/分钟，兼顾长尾与周期性，避免直接标量回归在边界处的不连续问题。
- **实验设计较扎实**：13 个跨领域日志、5 seeds、temporal split、feature-stripped 对照、多类消融、干扰列鲁棒性测试和注意力因果分析。
- **可解释性与实用性**：注意力权重可提供逐事件特征重要性，抗干扰测试说明其适合字段多而杂的企业日志。
- **资源效率**：单张 L40S、低于 100 GPU-hours，训练成本相对可控。

## 8. 不足与局限
- **预测任务范围有限**：目前仅做单步下一事件预测，未覆盖多步预测、剩余时间预测等更广泛的 PPM 任务。
- **模态覆盖仍有限**：只处理类别、数值、文本，未纳入图像、音频、图结构或跨 case 关系等模态。
- **基线覆盖不完全**：主实验主要对比 TPP/GRU 基线，未直接与 ProcessTransformer、MiTFM、Text-aware predictive monitoring 等 PPM 方法全面比较。
- **IFTPP 比较不完整**：IFTPP 在 11/13 数据集时间预测发散，被排除出 MAE 表，使时间预测对比缺少一个强度量模型。
- **通用性有边界**：在 BPI-2015 等特征无益甚至有害的数据集上，上下文特征可能带来过拟合风险；说明“通用”仍受数据规模、活动基数、字段质量影响。
- **文本编码较固定**：使用冻结的 distilbert-base-uncased 均值池化，未探索领域适配或微调文本编码器。
- **数据划分与偏差风险**：采用单一时间切分和 seed 42，可能受时间分布偏移影响；事件日志可能含敏感属性，贷款、医疗等高风险场景存在偏差与公平性风险。
- **算力报告较粗**：只给出总 GPU-hours 上限，未细分各实验训练成本。
- **部署限制**：模型吸收所有可用特征，实际部署需审计 PII、访问控制和公平性，不能替代高风险决策中的人类判断。
