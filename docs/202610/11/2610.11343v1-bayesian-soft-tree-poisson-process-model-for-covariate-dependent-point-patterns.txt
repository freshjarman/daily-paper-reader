# Bayesian Soft-Tree Poisson Process Model for Covariate-Dependent Point Patterns 

## Pulong Ma Department of Statistics, Iowa State University Ames, IA 50011, USA 

Abstract 

Estimating covariate-dependent intensity functions from spatial point pattern is challenging when the integrated intensity function cannot be evaluated analytically. This challenge becomes even worse in Bayesian inference due to repeated integration of the intensity function over the high-dimensional covariate space. This paper develops a Bayesian soft-tree Poisson process model that combines adaptive covariate partitioning with smooth intensity function. The key idea is to use soft gating functions to smooth transitions between partition boundaries in a tree generating process while preserving analytic evaluation of integrated intensity. A Bayesian CART prior is adopted to learn the partition structure from data. Given the partition tree, conjugate priors are assigned on leaf parameters to enable analytic marginal likelihood computation. This paper also develops a reversible-jump Markov chain Monte Carlo (RJ-MCMC) algorithm for posterior inference. Posterior consistency is established for the proposed model with respect to the Hellinger distance. Extensive simulation studies and an application to wildfire data confirm the advantages of the proposed method over existing methods. 

Keywords: Data augmentation; Soft decision tree; Point process; Posterior consis-tency 

# 1 Introduction 

Spatial point patterns are often collected in many scientific disciplines including climate science, ecology, biology, seismology (Cressie, 1993; Diggle, 2014; Gelfand and Schliep, 2018). Statistical analysis of these point pattens often relies on point processes. A popular class of point processes is Poisson (point) process (PP). Let X ∼ P P (λ) denote a Poisson process with intensity function λ on a domain D ⊂ Rd, where λ : D 7 → (0, ∞) is a locally integrable function. A constructive definition for PP is as follows. For any bounded subset B ⊂ D, the number of points in B, denoted by N(B), is Poisson distributed with rate Λ(B) := R 

> B

λ(x)dx; given N(B), the points in B are independently and identically distributed with location density f (x) := λ(x)/Λ(B). Here Λ(B) is referred to as total intensity (over B); see Møller and Waagepetersen (2004) for some backgrounds. If λ(·) is constant over D, X is called a homogeneous PP, otherwise X is an inhomogeneous PP. Modeling spatial point patterns requires flexible modeling for the intensity function. Given a realization x1: n := {x1, . . . , xn} ⊂ D of X, the likelihood given the intensity 1arXiv:2610.11343v1 [stat.ME] 8 Oct 2026 function is L(λ; x1: n) = exp (−Λ(D)) ∏ni=1 λ(xi). Several statistical methods have been proposed to model the intensity function. A well-known approach is to model the intensity function with a latent Gaussian process via a link function, resulting in so called the log-Gaussian Cox process (LGCP) (Møller et al., 1998) when a log link function is used. In LGCP, the mean function of the Gaussian process (GP) often incorporates covariates and the covariance function is used to capture spatial dependence. This class of models is often applied to environmental data with spatial locations, where covariance function is defined over a spatial domain. A potential limitation of this approach to deal with multiple (or high-dimensional) covariates is that these covariates are required to be known to calculate the random integral. To perform inference, a standard practice to compute this random integral is to use quadrature approaches with a dense grid points over spatial domain. Most often, the covariates are sparsely observed over finite number of spatial locations. A preprocessing step is often used to interpolate these covariates over the spatial domain so that the nu-merical integral can be approximated over the quadrature grids; see Møller et al. (1998); Rue et al. (2009); Simpson et al. (2016). Potential challenges in LGCP include the numerical approximation error for approximating the random integral and the lack of uncertainty quantification when interpolated environmental variables are used. For instance, GP related challenges arise when the number of quadrature grid points is large and the under-lying smoothness of intensity is controlled by the smoothness of GP, which is often chosen to be second-order stationary in practice despite the fact that environmental processes often have heterogeneous spatial dependence structure over the entire domain. To address the computational challenges associated with LGCP, several strategies have been proposed in the literature. For GP challenges, efficient GP models such as Gaussian Markov random field (Rue et al., 2009) have been used to exploit sparse matrix operations for efficient computations (Rue et al., 2009; Simpson et al., 2016). To bypass the numerical integration problem in likelihood, data augmentation techniques are also exploited to allow efficient inference (Adams et al., 2009; Donner and Opper, 2018), where sigmoid GP is used for modeling intensity function via the sigmoid link function. Another approach for modeling the intensity functions is focused on domain partition-ing methods. Earlier methods include Voronoi tessellation (e.g., Barr and Schoenberg, 2010; Hinde and Miles, 1980; Meijering, 1953). More recently, tree-based methods (Lamprinakou et al., 2023; Lu et al., 2026; Ma, 2026) have been used for modeling intensity functions. Voronois tessellation method often assumes the piecewise constant over Voronoi cells; in contrast, tree-based methods represent the intensity function over a single tree or additive trees that are formed by random recursive partitioning of the domain so that partition tree can be learnt from the data. In particular, Ma (2026) represents the intensity function as piecewise constants in a single tree structure that is formed by Bayesian CART prior (Chipman et al., 1998, 2002). Lamprinakou et al. (2023) develop a statistical model called BART-PP that uses Bayesian additive regression trees (BART; Chipman et al., 2010) for log-intensity functions. Anon-Bayesian formulation is given by Lu et al. (2026) who develop a statistical model called XGBoostPP that uses XGBoost (Chen and Guestrin, 2016; Natekin and Knoll, 2013). 2Additive tree ensembles such as XGBoostPP and BART-PP are generally more flexible than single tree models for function approximation. A potential limitation for XGBoostPP is that it does not provide uncertainty estimates for intensity function from the model; in contrast, BART-PP can provide Bayesian uncertainty quantification. However, BART-PP does not learn hyperparameters in leaf nodes but fixes them a priori , which would underestimate the uncertainty. A key benefit of tree-based methods is its ability to deal with potentially high-dimensional covariate space without requiring fully observed covariates over the domain since tree-based methods such as Ma (2026) and Lamprinakou et al. (2023) can obtain closed form formula in evaluating the random integral in the likelihood function due to piecewise constants assumptions. Recognizing the benefits of tree-based models, this paper focuses on modeling the intensity function directly through a tree structure. As noted in Ma (2026), a potential limitation in using a hard-split tree is that the resulting posterior of the intensity function can have very sharp transitions across partition boundaries. To address this limitation, this paper exploits the ideas (Irsoy et al., 2012; Jordan and Jacobs, 1994; Linero and Yang, 2018) to use a soft-gating function to enable smooth transitions across partition boundaries, where the degrees of smoothness across the boundary transitions will be estimated in a Bayesian paradigm. While it may seem that this would destroy the analytic expressions of the random integral, this paper will design a strategy to maintain analytic expression for the random integral, thus reducing the integral to one-dimensional closed-form factors, with numerical fallback when needed for stability. To allow adaptive estimation of the partitions, this paper couples the Bayesian CART prior (Chipman et al., 1998, 2002) with soft gating strategy to learn the partition. This leads to a hierarchical specification for the proposed model. To make Bayesian inference, this paper develops a novel data-augmentation strategy to address the computational challenges since with soft-gating functions, the likelihood of the intensity parameter with each leaf node is not conjugate to its prior distribution. This computational challenge is addressed by introducing a latent variable for each observation to mark their memberships within a node. Under this augmentation, the augmented likelihood is shown to allow conjugate update for intensity parameters so that Bayesian inference could be performed efficiently. 

Contributions: The contributions of this paper ranging from statistical method, compu-tational algorithm, and theory. In particular, this paper builds a Bayesian soft Poisson point process tree ( S-PPT ) model for modeling point patterns in a potentially high-dimensional covariate space, for which many existing methods fail to cope with in many real-world applications. The paper also develops an efficient Bayesian inference procedure through a data-augmentation technique to allow conjugate updates for intensity parameters. Finally the paper also establishes strong consistency of the resulting posterior distribution under Hellinger distance in an asymptotic framework. 32 Statistical Method

# 4 Numerical Illustrations 

The goal of numerical examples is to study its performance under both low-dimensional covariate space and high-dimensional covariate space. In low-dimensional space ( d ≤ 2), we can compare the proposed model with the widely-used LGCP since there is not available implementation for higher-dimensional space with d > 2. In particular, we will use the INLA-approximated LGCP available in the R package inlabru (Lindgren et al., 2024). For 

d > 2, BART-PP (Lamprinakou et al., 2023) and PPT (Ma, 2026) are closely related Bayesian competitors, however there is no available software code available for BART-PP. However, the code for XGBoostPP (Lu et al., 2026) is available online and will be used for comparison in higher dimensions. The PPT model is very similar to the proposed model except that PPT uses hard split for the model and sequential Monte Carlo (SMC) method for inference. It is implemented in the R package poistree 1.To evaluate performance of the proposed model, we will mainly focus on comparing the estimated intensity function via scaled root mean square error (sRMSE) and log posterior predictive density (lppd) over testing datasets. Their formulas are given in Appendix S.2.1. sRMSE assesses the property of mean estimator of intensity function while lppd assess the predictive performance for the entire predictive distribution which is a desirable metric for evaluating Bayesian models. Smaller sRMSE indicates better estimation of intensity function while larger lppd indicates better performance of predictive distribution for the intensity. All the numerical experiments are performed on a 24GB memory Macbook Pro with Apple M4 Pro chip and 20 cores. All the timing results are reported in minutes.

# 5 Concluding Remarks 

This paper develops a Bayesian soft Poisson process tree (S-PPT) model for estimating intensity functions in a possibly high-dimensional covariate space. The proposed model ex-ploits the Bayesian CART prior for learning tree partitions and integrates the soft-decision tree idea to smooth over partition boundaries. To carry out efficient Bayesian inference, this paper develops a data augmentation technique to allow closed-form conjugate sampling for intensity parameters in a partially collapsed Gibbs sampler. The theoretical result also shows strong consistency of the posterior distribution for estimating continuous intensity functions, thus providing good frequentist property of the proposed model with a slight modification on the tree prior. There are also several future research directions that could be pursued. First this model can be extended to an additive tree method to exploit the benefits of ensemble methods. 14 PPT S−PPT XGBoostPP 0 100 200 300 0 100 200 300 0 100 200 300 0100 200 300 400 Observed held−out count Predictive median and 95% interval Figure 3: Estimated count intensity function for California wildfire data under PPT, S-PPT, and XGBoostPP. Current computational strategy with closed-form random integral evaluation relies on axis-aligned partitions for rectangular regions. This might be relaxed if the domain is convex but not necessarily rectangular. Finally, the tree update with standard RJ-MCMC algorithm could be further improved using better proposals (e.g., Pratola, 2016) for more efficient tree search or the sequential Monte Carlo method (Ma, 2026).
