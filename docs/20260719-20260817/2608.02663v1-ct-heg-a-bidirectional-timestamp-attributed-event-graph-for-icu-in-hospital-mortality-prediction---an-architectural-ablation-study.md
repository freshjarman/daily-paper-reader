## 摘要
准确的ICU死亡率预测需要对异构实体类型的不规则临床观测进行建模。现有的序列模型能处理不规则采样，但忽略了类型化的关系结构；现有的图模型则假设输入是固定间隔的。我们引入了连续时间异构电子健康记录图（CT-HEG）模式，并评估哪些架构选择驱动了预测性能。CT-HEG将每次ICU住院编码为一个类型化、带时间戳的图，包含三种节点类型（就诊、生命体征、实验室事件）和二维边属性（t_hours/48, value_norm），在无需插补的情况下对时间与数值进行编码。我们将CT-HEG实例化为CHIRP-Net，这是一个四层异构GATv2Conv网络，在MIMIC-IV v3.1（31,142次ICU住院，住院时间≥48小时，死亡率13.4%）上进行了评估，使用五个种子和自助置信区间，并与逻辑回归、mTAND、Transformer和GRU-D以及消融研究进行了比较。CHIRP-Net实现了5种子平均AUROC 0.8449±0.0071（AUPRC 0.4958±0.0209）；集成模型实现了AUROC 0.8618（95% CI：0.8485-0.8745）。移除反向边会使观测节点与就诊读出断开连接，AUROC降低0.1968±0.0073。时间注意力边特征贡献了0.0247±0.0093的AUROC。将异构边类型合并为一种关系（参数减少7倍）在所有种子上均优于完整模型。校准后的ECE为0.0307。时间与人口统计子群分析已探索但未在此报告，留待后续工作。双向连接对于模型使用其输入至关重要，CT-HEG在验证集拟合温度缩放后校准良好。这些结果支持CT-HEG用于不规则电子健康记录数据，但在作出任何稳健性声明之前，仍需外部验证、预先指定的时间评估和人口统计公平性审计。代码：https://github.com/nasiruddinstudents-ctrl/chirp-net-mimic-iv。

## Abstract
Accurate ICU mortality prediction requires modeling irregular clinical observations across heterogeneous entity types. Existing sequence models handle irregular sampling but ignore typed relational structure; existing graph models assume fixed-interval inputs. We introduce the Continuous-Time Heterogeneous EHR Graph (CT-HEG) schema and evaluate which architectural choices drive predictive performance. CT-HEG encodes each ICU stay as a typed, timestamped graph with three node types (visit, vital, lab_event) and 2D edge attributes (t_hours/48, value_norm) encoding timing and value without imputation. We instantiate CT-HEG as CHIRP-Net, a four-layer heterogeneous GATv2Conv network, evaluated on MIMIC-IV v3.1 (31,142 ICU stays, LOS>=48h, 13.4% mortality) with five seeds and bootstrapped confidence intervals, against logistic regression, mTAND, a Transformer, and GRU-D, plus an ablation study. CHIRP-Net achieved 5-seed mean AUROC 0.8449+/-0.0071 (AUPRC 0.4958+/-0.0209); the ensemble achieved AUROC 0.8618 (95% CI: 0.8485-0.8745). Removing reverse edges disconnected observation nodes from the visit readout, cutting AUROC by 0.1968+/-0.0073. Time-attentive edge features contributed 0.0247+/-0.0093 AUROC. Collapsing heterogeneous edge types into one relation (7x fewer parameters) outperformed the full model on all seeds. Post-calibration ECE was 0.0307. Temporal and demographic subgroup analyses were explored but not reported here, pending follow-up work. Bidirectional connectivity was necessary for the model to use its inputs at all, and CT-HEG was reasonably well calibrated after validation-fitted temperature scaling. These results support CT-HEG for irregular EHR data, while external validation, a pre-specified temporal evaluation, and a demographic fairness audit remain necessary before any claim of robustness. ## 1. 核心问题与整体含义（研究动机与背景）

ICU院内死亡率预测是重症医学中最具挑战性的任务之一。论文指出真实ICU数据存在三大结构性挑战：
- **不规则采样与系统性缺失**：ICU数据由临床驱动而非协议驱动，测量频率本身隐含患者危重程度的临床信号，传统插补方法会混淆"真实稳定"与"未测量"；
- **实体与关系异构性**：一次ICU住院不是单一时间序列，而是由患者、就诊、生命体征、实验室事件、药物、诊断等异构实体及其语义关系构成的系统，扁平化处理会丢失关系语义；
- **可解释性缺口**：临床医生不会采信黑盒风险评分，而现有GNN解释方法多为相关性而非因果性。

**核心矛盾**：现有序列模型能处理不规则采样但忽视结构；现有图模型能建模关系但假设固定间隔输入；因果解释方法只适用于同质静态图。CT-HEG与CHIRP-Net旨在弥合前两个缺口（不规则采样与异构性），将因果可解释性留待未来工作。论文的定位不是宣称SOTA，而是通过系统的架构消融实验回答"哪些架构选择真正驱动了预测性能"。

## 2. 方法论

### 2.1 CT-HEG图模式
- 将每次ICU住院编码为类型化、带时间戳的异构图，节点类型$\Phi$为{visit（就诊）、vital（生命体征）、lab event（实验室事件）}；
- 边属性为二维向量 $e_{u\rightarrow v} = (t_{hours}/48, value_{norm}) \in \mathbb{R}^2$，将观测时间与数值直接编码在边上，**无需任何插补**；
- 中心设计理念：时间的不规则性被编码在边时间戳中，成为图的一等公民，而非通过遮罩张量或插值来处理；
- 图离线构建，基于固定的48小时入院快照，保证回顾性评估是前瞻性部署的有意义代理。

### 2.2 CHIRP-Net架构
- 类型条件输入嵌入：每种节点类型的特定编码器，拼接可学习的通道/分析物身份嵌入；
- 时间注意力边编码：通过GATv2Conv（edge dim=2）将边属性纳入注意力权重计算，实现"连续时间"注意力（时间戳作为连续值边属性而非离散桶）；
- 异构消息传递：四层HeteroConv（GATv2Conv，hidden=192，heads=4，dropout=0.25），每层后接残差连接与LayerNorm，消息传递公式为 $h_v^{(l+1)} = \sigma(W_{\phi(v)}h_v^{(l)} + \sum_{r,u}\alpha^{(r)}_{u\rightarrow v}\cdot W_r h_u^{(l)})$；
- 读出：从visit节点经MLP输出死亡logit，使用BCE损失，辅以LOS预测的MSE正则化（权重$\lambda=0.05$）。

### 2.3 消融实验设计
三个核心消融：(i) 移除反向边（连通性/可达性检查）；(ii) 移除时间注意力边特征（常数边属性）；(iii) 将异构边类型合并为单一同质关系。

## 3. 实验设计

### 3.1 数据集
- **MIMIC-IV v3.1**：31,142例首次ICU住院（每位患者仅保留首次住院），LOS≥48小时，院内死亡率13.4%；
- 特征：17个生命体征通道和36项常规实验室检测，以带时间戳的vital/lab→visit边形式编码；
- 划分：70/15/15训练/验证/测试，按死亡率分层，固定随机种子42；患者级不重叠由队列构建保证（31,142行、31,142个唯一subject_id）。

### 3.2 对比方法
实际运行的基线包括：逻辑回归（48小时生命体征/实验室摘要统计量，53个特征）、GRU-D（单次运行）、mTAND（5个种子）、4层Transformer（5个种子）。

## 6. 主要结论与发现

1. **双向边是结构必需，而非锦上添花**：移除反向边导致AUROC下降0.1968±0.0073（降至0.6482±0.0008，低于逻辑回归基线），4层网络退化为单一嵌入查找——这是确定性架构瓶颈而非调参问题；
2. **时间注意力边特征贡献一致但较小**：移除时间戳信息使AUROC下降0.0247±0.0093，验证了连续时间编码的价值；
3. **异构边类型合并反而更好**：将4种边关系合并为单一关系，AUROC为0.8638±0.0036，优于完整异构模型的0.8449±0.0071，同时参数减少约7倍（345,794 vs. 2,448,578）——论文将其报告为"真实发现"而非设计背书；
4. **CHIRP-Net主模型**：5种子平均AUROC 0.8449±0.0071，超过逻辑回归基线7.6个点，但只比GRU-D高0.002 AUROC（远小于其自身种子间标准差0.0071），不构成可靠的优势声明；
5. **集成与校准**：5-checkpoint集成AUROC 0.8618，温度缩放后测试集ECE=0.0307。

## 7. 优点

- **架构消融的严谨性**：明确区分"结构必需"与"信息增益"两类消融，通过不同效应的不对称性揭示组件的功能角色（反向边=信息传播通道；时间特征=注意力细化）；
- **诚实的方法论态度**：主动撤回无效的时间泛化分析，公开报告基线比较的不公平性（GRU-D单次运行、无调优），坦白报告"异构关系未带来提升"这一不利发现；

- **可复现性**：开源BSD-3许可代码与预处理管道，报告详细的基线训练协议表（参数数、优化器、学习率、批次大小、早停规则），保证实验可复现；

## 8. 不足与局限
