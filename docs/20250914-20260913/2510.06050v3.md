## 摘要
时间点过程（TPP）是建模连续时间事件序列的基本工具，但大多数现有方法依赖于自回归参数化，受限于其顺序采样。最近的非自回归、扩散式模型通过在离散马尔可夫链中通过事件插入和删除在噪声和数据之间联合插值，缓解了这些问题。在这项工作中，我们推广了这一视角，并为TPP引入了一种编辑流过程，通过插入、删除和替换编辑操作将噪声传输到数据。通过在连续时间马尔可夫链框架内学习瞬时编辑率，我们获得了一个灵活且高效的模型，有效减少了生成过程中所需编辑操作的总数。实证结果表明，我们无条件训练的模型在基准TPP上的广泛无条件与条件生成任务中具有生成灵活性。

## Abstract
Temporal point processes (TPPs) are a fundamental tool for modeling event sequences in continuous time, but most existing approaches rely on autoregressive parameterizations that are limited by their sequential sampling. Recent non-autoregressive, diffusion-style models mitigate these issues by jointly interpolating between noise and data through event insertions and deletions in a discrete Markov chain. In this work, we generalize this perspective and introduce an Edit Flow process for TPPs that transports noise to data via insert, delete, and substitute edit operations. By learning the instantaneous edit rates within a continuous-time Markov chain framework, we attain a flexible and efficient model that effectively reduces the total number of necessary edit operations during generation. Empirical results demonstrate the generative flexibility of our unconditionally trained model in a wide range of unconditional and conditional generation tasks on benchmark TPPs.

## 1. 核心问题与整体含义

- **研究背景**：时间点过程（TPP）用于建模连续时间中的事件序列，广泛应用于金融、医疗、社交网络、交通等领域。事件到达时间和数量均具有随机性。
- **核心问题**：现有神经 TPP 方法大多采用**自回归参数化**，即给定历史条件建模下一个事件的强度/密度。这种分解方式存在三大固有局限：
  - 采样复杂度随序列长度线性增长；
  - 多步生成中误差逐步累积；
  - 条件生成被限制为仅能执行预测（forecasting）任务。
- **已有进展**：ADD THIN 和 PSD IFF 等非自回归扩散式方法通过插入/删除操作构造离散马尔可夫链，在噪声与数据之间插值，缓解了上述问题。Havasi et al. (2025) 提出的 Edit Flow 在离散 token 序列上引入插入、删除、替换三种编辑操作。
- **本文目标**：将 Edit Flow 推广到连续时间的 TPP 场景，提出 **EDITPP**——首个基于连续时间编辑操作的 TPP 生成框架，统一了 TPP 的随机集合插值方法与离散序列的 Edit Flow。

## 2. 方法论

### 2.1 核心思想

- 定义连续时间马尔可夫链（CTMC），通过三种原子编辑操作——**插入（insert）、替换（substitute）、删除（delete）**——将噪声序列 $t_0 \sim p_{\text{noise}}$ 传输到数据序列 $t_1 \sim q_{\text{target}}$。
- 学习每种编辑操作的**瞬时速率**，实现灵活且高效的生成，并减少所需编辑操作总数。

### 2.2 编辑操作定义

- **状态空间** $X_T$：所有带边界填充（$t^{(0)}=0$，$t^{(n+1)}=T$）的有限有序事件序列。
- **插入** $\text{ins}(t, i, j)$：在第 $i$ 与第 $i+1$ 个事件之间将区间量化为 $\text{bins}$ 个等距 bin，插入位置由 bin 索引 $j$ 和均匀去量化因子 $\alpha$ 确定。不同 $i$ 的 bin 互不重叠，保证插入操作的唯一性。
- **替换** $\text{sub}(t, i, j)$：将第 $i$ 个事件在最大移动距离 $\delta$ 范围内量化为 $b_{\text{sub}}$ 个 bin，替换后重新排序。替换操作由被替换事件的位置唯一确定。
- **删除** $\text{del}(t, i)$：直接移除第 $i$ 个事件。

三种操作满足三个关键性质：(i) 结果仍是合法 TPP 序列；(ii) 有效操作数与位置 $i$ 无关，便于高效参数化；(iii) 任意两状态间至多存在一种唯一操作，简化训练损失。

### 2.3 速率参数化

给定当前状态 $t_s$，转移速率分解为：

$$u_s^\theta(\text{ins}(t_s,i,j)|t_s) = \lambda_{s,i}^{\text{ins}}(t_s) \cdot Q_{s,i}^{\text{ins}}(j|t_s)$$

$$u_s^\theta(\text{sub}(t_s,i,j)|t_s) = \lambda_{s,i}^{\text{sub}}(t_s) \cdot Q_{s,i}^{\text{sub}}(j|t_s)$$

$$u_s^\theta(\text{del}(t_s,i)|t_s) = \lambda_{s,i}^{\text{del}}(t_s)$$

其中 $\lambda$ 为总速率，$Q$ 为离散化 bin 上的类别分布。

### 2.4 辅助对齐空间

- 直接匹配边缘化条件速率 $u_s(t|t_1,t_0)$ 是棘手的，因为需考虑所有可能产生 $t$ 的编辑。
- 引入辅助对齐空间，使用 **Needleman-Wunsch 算法**对 $t_0$ 和 $t_1$ 的非边界事件进行最小代价对齐，代价函数精心设计以保证对齐结果对应合法的 ins/sub/del 操作。
- 对齐后，元素级混合路径 $z_s \sim p_s(z_s|z_0,z_1)$ 使学习问题可处理。

### 2.5 训练目标

优化 Bregman 散度：

$$\mathcal{L} = \mathbb{E}_{(z_0,z_1)\sim\pi, s, p_s} \left[ \sum_{\omega\in\Omega(t_s)} u_s^\theta(\omega|t_s) - \sum_{z_s^{(i)}\neq z_1^{(i)}} \frac{\dot{\kappa}_s}{1-\kappa_s} \log u_s^\theta(\omega(z_s^{(i)},z_1^{(i)})|t_s) \right]$$

其中 $\Omega(t_s)$ 为当前状态所有可应用编辑操作的集合，$\kappa_s$ 为噪声调度。

### 2.6 采样

- 使用 Euler 近似前向模拟 CTMC，从 $s=0$ 到 $s=1$。
- 每步长度 $h$ 内，插入以概率 $h\lambda^{\text{ins}}$ 发生，删除/替换以概率 $h(\lambda^{\text{del}}+\lambda^{\text{sub}})$ 发生，替换与删除的比例由速率决定。
- **条件采样**：给定二值时间掩码 $c: T \to \{0,1\}$，强制条件子序列遵循噪声插值，其余部分自由演化，可统一支持预测和外推等任务。

### 2.7 模型架构

- 基于 **Llama** transformer，使用 **FlexAttention** 原生支持变长序列。
- 事件时间通过正弦嵌入 + MLP 转为 token 嵌入，$s$ 和序列长度作为额外 token 前置。
- 输出经 MLP 映射为各编辑操作的速率参数：$\lambda = \exp(\lambda_M \tanh(h))$，$Q = \text{softmax}(h)$。

## 6. 主要结论与发现

- **无条件生成**：EDITPP 在所有评估指标上取得最佳排名，显著优于 IFTPP、ADD THIN 和 PSD IFF，能强匹配测试集分布。
- **条件生成（预测）**：EDITPP 在多数数据集和指标上匹配或超越基线。值得注意的是，**无条件训练的 EDITPP 在预测任务上优于显式自回归训练的 IFTPP**，验证了自回归模型在预测中误差累积的问题。
- **编辑效率**：EDITPP 平均使用 199.65 次编辑操作，少于 PSD IFF 的 234.52 次，即使将替换操作计为两次编辑仍具优势。
- **采样速度**：EDITPP 采样运行时间显著低于 ADD THIN 和 PSD IFF（如 R/C 数据集上 1505.68 ms vs. 3913.78 ms vs. 17689.36 ms）。
- **计算-质量权衡**：作为连续时间模型，EDITPP 可在推理时灵活调整采样步数，实现计算与质量的权衡，且质量提升随步数增加迅速递减，存在大幅加速空间。
- **Inpainting 优势**：提供过去和未来上下文时，生成中间片段的质量显著优于仅基于过去的预测。
