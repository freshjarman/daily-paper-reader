## 摘要
利用带标记的时间点过程（MTPP）对多种事件类型的事件序列进行建模，为揭示支配性动态规律和预测未来事件提供了一种有原则的方法。当前用于MTPP推断的神经网络方法依赖于为每个目标系统训练单独的专用模型。我们采取了一种截然不同的方法：借鉴摊销推断和上下文学习，预训练一个深度神经网络，使其能够根据由事件序列集合定义的上下文，在上下文中推断事件历史的条件强度函数。预训练在一个大型合成数据集上进行，该数据集由从广泛分布的霍克斯过程中采样的MTPP组成。一旦预训练完成，我们的点过程基础推理模型（FIM-PP）无需任何额外训练即可从真实世界数据中估计MTPP，或快速微调以适应目标系统。实验表明，这种摊销方法在常见基准数据集上的下一事件预测性能与专用模型相当。

## Abstract
Modeling event sequences of multiple event types with marked temporal point processes (MTPPs) provides a principled way to uncover governing dynamical rules and predict future events. Current neural network approaches to MTPP inference rely on training separate, specialized models for each target system. We pursue a radically different approach: drawing on amortized inference and in-context learning, we pretrain a deep neural network to infer, in-context, the conditional intensity functions of event histories from a context defined by sets of event sequences. Pretraining is performed on a large synthetic dataset of MTPPs sampled from a broad distribution of Hawkes processes. Once pretrained, our Foundation Inference Model for Point Processes (FIM-PP) can estimate MTPPs from real-world data without any additional training, or be rapidly finetuned to target systems. Experiments show that this amortized approach matches the performance of specialized models on next-event prediction across common benchmark datasets.

# FIM-PP 论文中文总结

## 1. 核心问题与整体含义

- **研究动机**：带标记时间点过程（MTPP）是建模异步、不规则事件序列（如神经脉冲、社交媒体转发、金融交易、流行病传播）的经典框架。现有神经网络方法（如 Neural Hawkes、Transformer Hawkes）通常需要为**每个目标系统单独训练专用模型**，缺乏可迁移性，每遇到新数据集就要从头训练。
- **核心问题**：能否像 NLP 领域的基础模型那样，预训练一个通用模型，使其能够**零样本（zero-shot）** 地从上下文事件序列中推断 MTPP 的条件强度函数，而无需针对每个系统重新训练？
- **整体含义**：本文提出 **FIM-PP**（Foundation Inference Model for Point Processes），是首个面向时间点过程的基础推理模型。它借鉴摊销推断（amortized inference）与上下文学习（in-context learning）范式，在大规模合成 Hawkes 过程上预训练，从而在真实数据上实现零样本推断或快速微调。

## 2. 方法论

### 核心思想
- 采用 **FIM（Foundation Inference Model）** 范式：不直接预测未来事件，而是**直接估计条件强度函数** $\hat{\lambda}(t, \kappa \mid H_t)$，保留可解释性。
- 通过在大规模合成 MTPP 数据上预训练，让模型学会"从上下文推断动力学规则"，实现摊销推断。

### 合成数据生成
- 定义广泛的 MTPP 先验分布，条件强度形式为：
  $$\lambda(t, \kappa \mid H_t) = \max\left(0,\ \mu_\kappa(t) + \sum_{(t',\kappa')\in H_t} z_{\kappa\kappa'}\gamma_{\kappa\kappa'}(t-t')\right)$$
- 覆盖多种过程族：经典 Hawkes（指数核）、Poisson、周期过程（正弦基强度）、Gamma 初始激发过程、Rayleigh 非单调核等。
- 交互类型通过 $z_{\kappa\kappa'} \in \{-1, 0, 1\}$ 随机采样，覆盖**兴奋、抑制、无影响**三种关系。
- 使用 Ogata 修正薄化算法（thinning）模拟事件序列。

### 模型架构（FIM-PP）
- **上下文编码**：对每条序列独立编码（事件时间、标记、间隔时间），经 Transformer 编码器 + 固定查询注意力得到序列嵌入 $c_j$，再经第二个 Transformer 编码器组合所有序列嵌入。
- **上下文感知历史编码**：历史事件嵌入作为 Transformer 解码器的查询（queries），上下文表示作为键和值（keys/values），得到统一编码 $h_t^{hist}$。
- **强度参数化**：将 $h_t^{hist}$ 与标记编码拼接，投影到三个非负参数 $\hat{\mu}, \hat{\alpha}, \hat{\beta}$，定义：
  $$\hat{\lambda}(t, \kappa' \mid H_t) = \hat{\mu} + (\hat{\alpha} - \hat{\mu})\exp\left(-\hat{\beta}(t - t_{n_{hist}})\right)$$
  参数本身依赖历史与标记，因此可表达丰富的局部强度行为。
- **实例归一化**：按上下文最大间隔时间缩放时间输入，使模型对时间尺度不变。

### 训练与微调
- 训练目标为下一事件负对数似然（NLL），积分项用蒙特卡洛近似（100 个采样点）。
- 微调时在评估数据集的训练集上继续最小化 NLL，几分钟即可完成。

## 3. 实验设计

### 数据集
- **5 个真实世界数据集**：TAXI、TAOBAO、STACK OVERFLOW、AMAZON、RETWEET（沿用 Zeng et al. 2024 的预处理与划分）。
- **合成数据集**：用于验证零样本泛化能力，包括 Gamma 基强度、Poisson、Powerlaw 核、Rayleigh 核等（其中 Powerlaw 核**未出现在预训练分布中**）。

### Benchmark 与对比方法
- 沿用 **CDiff（Zeng et al., 2024）** 的实验设置与评估代码。
- 对比方法分两类：
  - **联合分布模型**：Dual-TPP、HYPRO、CDiff
  - **自回归模型**：强度基（NHP、A-NHP）与强度无关（IFTPP、TCDDM）
- **评估指标**：OTD（最优传输距离）、RMSE_e（事件计数误差）、RMSE_Δt、sMAPE_Δt、Acc（下一事件标记准确率）。
- **预测任务**：多事件预测（N=5, 10, 20）与下一事件预测（N=1）。

## 6. 主要结论与发现

- **零样本性能**：FIM-PP（zs）在多事件预测上可匹配或超越专用基线（如 TAXI、RETWEET），在 sMAPE_Δt 上表现突出。
- **微调后性能**：FIM-PP（f）在绝大多数任务和指标上**超越所有基线**，包括 CDiff。
- **下一事件预测**：在 TAOBAO 上零样本即达最佳；在 TAXI 上事件时间预测良好，但标记准确率低（因数据存在近乎确定性的标记交替模式，未包含在预训练先验中），微调后可恢复。
- **泛化能力**：对未出现在预训练中的 Powerlaw 核仍能较好估计，说明参数化足够通用。
- **预训练价值**：预训练提供良好初始化，微调收敛更快、最终性能更好（对比随机初始化）。
- **上下文规模**：约 500 条上下文路径后性能饱和，且不会因路径增多而退化。

## 7. 优点

- **范式创新**：首次将基础模型/上下文学习范式引入 MTPP，实现零样本推断，摆脱逐系统训练。
- **可解释性**：直接估计条件强度函数，保留物理可解释性（如兴奋/抑制交互）。
- **架构设计合理**：分层编码（序列内 + 序列间）+ 解码器注意力，兼顾可扩展性与上下文利用。
- **参数化灵活**：$\hat{\mu}, \hat{\alpha}, \hat{\beta}$ 依赖历史与标记，可表达 Hawkes 之外的复杂局部行为。
- **实用性强**：模型小（16M）、微调快（几分钟、<11GB 显存），适合资源有限用户。
- **实验严谨**：使用公开 benchmark 与代码，报告多次试验统计，消融充分。

## 8. 不足与局限

- **预训练分布非万能**：无法覆盖所有真实模式（如 TAXI 的标记交替/转移矩阵式动态），零样本在分布偏移下性能下降。
- **硬性约束**：受训练时最大标记数 $|K|$ 和最大序列长度限制，超出时无法充分利用上下文。
- **下一事件预测短板**：对高度规则的标记转移模式零样本表现差，需微调。
- **对比公平性存疑**：作者指出 CDiff 源码 bug，虽已修正报告，但可能影响部分对比结论。
- **实验覆盖有限**：下一事件预测仅 2 个数据集；未与 LLM 微调方法（如 TPP-LLM）直接对比。
- **未来方向**：需扩展预训练分布（加入交替/循环/转移矩阵动态），并探索强度无关方法与摊销框架的结合。
