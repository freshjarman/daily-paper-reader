## 摘要
标记时间点过程（MTPPs）提供了一个基于过去事件历史对异步事件序列进行建模的原则性框架。然而，大多数现有的MTPP模型依赖于通道混合策略，将来自不同事件类型的信息编码为单一的固定大小潜在表示。这种纠缠可能掩盖类型特定的动态，导致性能下降和过拟合风险增加。在这项工作中，我们引入了ITPP，一种新颖的通道独立MTPP建模架构，使用基于ODE的骨干网络通过编码器-解码器框架解耦事件类型信息。ITPP的核心是一种类型感知的倒置自注意力机制，旨在显式建模异构事件类型之间的通道间相关性。该架构增强了有效性和鲁棒性，同时减少了过拟合。在多个真实世界和合成数据集上的综合实验表明，ITPP在预测准确性和泛化能力上始终优于最先进的MTPP模型。

## Abstract
Marked Temporal Point Processes (MTPPs) provide a principled framework for modeling asynchronous event sequences by conditioning on the history of past events. However, most existing MTPP models rely on channel-mixing strategies that encode information from different event types into a single, fixed-size latent representation. This entanglement can obscure type-specific dynamics, leading to performance degradation and increased risk of overfitting. In this work, we introduce ITPP, a novel channel-independent architecture for MTPP modeling that decouples event type information using an encoder-decoder framework with an ODE-based backbone. Central to ITPP is a type-aware inverted self-attention mechanism, designed to explicitly model inter-channel correlations among heterogeneous event types. This architecture enhances effectiveness and robustness while reducing overfitting. Comprehensive experiments on multiple real-world and synthetic datasets demonstrate that ITPP consistently outperforms state-of-the-art MTPP models in both predictive accuracy and generalization.

## 1. 核心问题与整体含义

- **研究背景**：标记时间点过程（MTPP）为建模连续时间中的异步事件序列提供了数学框架，广泛应用于医疗、金融、交通等领域。其核心是条件强度函数 \(\lambda_m(t|\mathcal{H}_t)\)，刻画下一事件在时间与类型上的联合分布。
- **核心问题**：现有 MTPP 模型普遍采用**通道混合（channel-mixing）**策略，将不同事件类型的历史信息压缩进单一固定维度的隐表示。这种信息纠缠会掩盖类型特有的动态模式，引入噪声与干扰，导致预测性能下降并加剧过拟合风险。
- **整体含义**：论文提出 **ITPP**（channel-Independent marked Temporal Point Process），通过"先解耦、再显式建模通道间关联"的策略，将通道独立思想从多变量时间序列预测领域首次迁移到 MTPP 建模中，以提升模型的表达能力、鲁棒性与泛化性。

## 2. 方法论

### 核心思想
- 采用 **"编码—关联—解码"（encoding-correlation-decoding）** 三段式架构：编码与解码阶段对每个事件类型通道独立操作，中间插入类型感知倒置自注意力层显式捕获跨通道依赖。

### 关键技术细节

- **通道独立上下文编码（基于 ODE）**
  - 将不同事件类型视为独立通道，各通道用共享参数的神经 ODE 同时模拟状态演化。
  - 状态演化分两类：
    - **外推（Extrapolation）**：事件间隔内的平滑演化，由漂移函数 \(f_{\theta_f}\) 定义：\(dz_k(t) = f_{\theta_f}(z_k(t), t)dt\)，通过求解初值问题得到任意时刻状态。
    - **跳跃（Jump）**：事件发生引起的突变，由跳跃函数 \(g_{\theta_g}\) 定义：\(z_k(t^+_{k,i}) = g_{\theta_g}(z_k(t^-_{k,i}))\)。

- **类型感知倒置自注意力（Type-aware Inverted Self-attention）**
  - 与普通 Transformer 不同，通道（事件类型）并非同质条目，因此对每个通道使用**通道特定的偏置项**，而映射矩阵 \(W^Q, W^K, W^V\) 跨通道共享：
    - \(q_k(t) = W^Q z_k(t) + b^Q_k\)
    - \(k_k(t) = W^K z_k(t) + b^K_k\)
    - \(v_k(t) = W^V z_k(t) + b^V_k\)
  - 在通道维度上执行自注意力：\(\text{ATTN}(Q,K,V) = \text{softmax}(QK^T/\sqrt{d_k})V\)，并配合残差连接与层归一化。
  - 该设计同时保留事件类型的固有联系（通过偏置）与状态依赖的相关性（通过注意力）。

- **通道独立强度解码**
  - 由共享参数的解码网络 \(r_{\theta_r}\) 从 \(h_k(t)\) 得到各类型强度 \(\lambda_k(t) = r_{\theta_r}(h_k(t))\)。
  - 下一事件联合概率：\(f(t,k) = \lambda_k(t)\exp(-\int_{\bar{t}}^{t}\lambda(\tau)d\tau)\)，其中 \(\lambda(t)=\sum_k \lambda_k(t)\)。

- **训练**
  - 采用最大对数似然估计（MLE），损失为负对数似然（NLL）：\(\mathcal{L}_\theta(S) = -\sum_i \log\lambda_{m_i}(t_i) + \int_0^T \lambda(\tau)d\tau\)。
  - 梯度通过伴随敏感度方法（adjoint sensitivity method）反向求解 ODE 计算。

## 6. 主要结论与发现

- ITPP 在**所有真实数据集的 TM-NLL 上均取得最优**，显著优于次优模型。
- 在预测任务中，ITPP 在 6 个指标中的 5 个取得最优，仅在 Earthquake 的 F1 上略逊。
- 自注意力模型（THP/SAHP/AttNHP）并未在长序列上超越强 RNN 基线，说明自注意力缺乏对序列与时间信息的强表示。
- 通道混合的 ODE 模型（NeuralODE、ODE-GRU）仅在数据量最大的 StackOverflow 上表现良好，暗示其易过拟合；ITPP 通过通道独立策略解决了这一问题。
- 在类型数较多的数据集上，ITPP 显著改善 M-NLL，说明解耦设计有助于区分事件类型。
- 强度恢复实验中，ITPP 在 Poisson 与 Hawkes 数据集上 MAPE 最低，定性可视化也显示其强度曲线更贴合真值。
- 消融实验证实：移除通道独立性或倒置自注意力均导致性能明显下降，且通道独立性的收益在小数据集上更显著。
- 过拟合分析显示，LogNormMix 与 ODE-GRU 在 Earthquake 上测试损失明显反弹，而 ITPP 抗过拟合能力更强。
