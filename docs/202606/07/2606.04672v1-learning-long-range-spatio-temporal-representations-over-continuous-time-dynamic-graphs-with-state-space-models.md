## 摘要
连续时间动态图（CTDG）提供了一个更丰富的框架来捕获演化关系数据中的细粒度时间模式。长程信息传播是学习表示时的关键挑战，其中需要在长时间跨度上保留和更新信息。现有方法限制了模型捕获单跳或局部时间邻域，无法捕获多跳或全局结构模式。为了解决这个问题，我们从第一性原理推导出一个参数高效的状态空间建模框架用于连续时间动态图（CTDG-SSM）。我们首先引入连续时间拓扑感知高阶多项式投影算子（CTT-HiPPO），这是一种基于记忆的HiPPO新重构，用于联合编码时间动态和图结构。CTT-HiPPO的解通过将经典HiPPO解投影到拉普拉斯矩阵的多项式上获得，产生拓扑感知的记忆更新，该更新允许CTDG（CTDG-SSM）的等效状态空间公式。然后，使用零阶保持方法获得计算高效的离散公式用于模型实现。在动态链接预测、动态节点分类和序列分类的基准测试中，CTDG-SSM实现了最先进的性能。值得注意的是，在需要长程时间（LRT）和空间推理的数据集上，它取得了很大的性能提升。

## Abstract
Continuous-time dynamic graphs (CTDGs) provide a richer framework to capture fine-grained temporal patterns in evolving relational data. Long-range information propagation is a key challenge while learning representations, wherein it is important to retain and update information over long temporal horizons. Existing approaches restrict models to capture one-hop or local temporal neighborhoods and fail to capture multi-hop or global structural patterns. To mitigate this, we derive a parameter-efficient state-space modeling framework for continuous-time dynamic graphs (CTDG-SSM) from first principles. We first introduce continuous-time Topology-Aware higher order polynomial projection operator (CTT-HiPPO), a novel memory-based reformulation of HiPPO to jointly encode temporal dynamics and graph structure. The solution from CTT-HiPPO is obtained by projecting the classical HiPPO solution through a polynomial of the Laplacian matrix, yielding topology-aware memory updates that admit an equivalent state-space formulation for CTDGs (CTDG-SSM). Then a computationally efficient discrete formulation is obtained using the zero-order hold approach for model implementation.   Across benchmarks on dynamic link prediction, dynamic node classification, and sequence classification, CTDG-SSM achieves state-of-the-art performance. Notably, it achieves large performance gains on datasets that require long range temporal (LRT) and spatial reasoning.

- **整体含义**：本文提出首个面向CTDG的状态空间模型（SSM）框架CTDG-SSM，从第一性原理出发，将时间记忆压缩与图结构编码统一到一个在线状态更新过程中，旨在同时解决LRT和LRS问题，推动CTDG表示学习新范式。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：通过将经典HiPPO（高阶多项式投影）与图拉普拉斯的多项式滤波器结合，得到拓扑感知的记忆系数CTT-HiPPO；并证明这一系数的演化满足一个状态空间模型（CTDG-SSM），从而在连续时间上联合建模时空变化。
- **关键技术细节**：
    - **CTT-HiPPO**：观测节点特征 $X(t)$ 被建模为：$X(t) = p(L_\tau) H_\tau g(t)$，其中 $p(L_\tau)$ 是拉普拉斯多项式（K阶图滤波器），$g(t)$ 是正交多项式基，$H_\tau$ 为拓扑感知的记忆系数。系数通过最小化残差得到：$H_\tau = p(L_\tau)^{-1} H_\tau^{HiPPO}$，即经典HiPPO解经逆图滤波投影。
    - **CTDG-SSM（连续形式）**：对区间 $s \in [\tau, \tau^+)$，记忆系数 $H_s$ 满足 ODE：
        $$\frac{dH_s}{ds} = -H_s \frac{A^\top}{M(s)} - p(L_s)^{-1} \frac{dp(L_s)}{ds} H_s + p(L_s)^{-1} X(s) \frac{B^\top}{M(s)}$$
        其中 $A,B$ 为SSM系统矩阵，$M(s)$ 为归一化项。该式显式包含结构变化项 $dp(L_s)/ds$，区别于静态图SSM。
    - **离散化**：采用零阶保持（ZOH）假设，得到离散递归式：
        $$H[k+1] = \bar{A}_{L[k]} H[k] \bar{A} + \bar{B}(L[k], X[k])$$
        其中 $\bar{A}_{L[k]} = \exp(-p(L[k])^{-1}(p(L[k])-p(L[k-1])))$，$\bar{A} = \exp(-\Delta[k] A^\top)$，$\bar{B}$ 通过数值积分（高斯-勒让德求积）高效实现。
    - **架构实现**：分为子图采样（提取批量节点的Nu最近邻）、特征编码（拼接节点/边/时间特征）、CTDG-SSM模块（堆叠归一化+残差+GeLU）、记忆维护与解码（用于链接预测/节点分类）。
- **理论性质**：证明了CTT-HiPPO系数的鲁棒性（对图扰动的误差有上界）和CTDG-SSM的置换等变性。

### 7. 优点

- **理论奠基**：从第一性原理推导出CTDG的SSM，给出连续和离散形式、鲁棒性、等变性证明。

- **参数高效**：轻量级设计，适合资源受限场景。
- **计算高效**：ZOH离散化、子图采样、数值求积策略有效控制复杂度，训练开销低于许多长程模型。

### 8. 不足与局限

- **线性滤波器限制**：当前采用固定多项式（可学习系数）作为图滤波器，可能无法表达更复杂的非线性拓扑模式。论文自身指出未来可借助GNN学习更通用的算子。
