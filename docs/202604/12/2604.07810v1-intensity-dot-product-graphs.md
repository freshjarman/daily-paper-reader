## 摘要
潜在位置随机图模型通常在选定样本量后将节点集视为固定，而基于图函数和随机测度的构造允许更多随机性，但代价是几何可解释性较弱。我们引入了强度点积图（IDPGs），它通过用欧几里得潜在空间上的泊松点过程替换固定的潜在位置集合，扩展了随机点积图。这产生了一个具有随机节点群体、RDPG风格的点积亲和力以及将连续潜在结构与有限观测图联系起来的人口水平强度的模型。我们定义了热图和期望算子作为概率矩阵的连续类比，证明了连接邻接奇异值与算子谱的谱一致性结果，将该构造与图函数和有向图函数表示进行了比较，并展示了经典RDPG如何在集中极限中出现。由于该模型由演化强度参数化，通过偏微分方程的时间扩展自然产生。

## Abstract
Latent-position random graph models usually treat the node set as fixed once the sample size is chosen, while graphon-based and random-measure constructions allow more randomness at the cost of weaker geometric interpretability. We introduce \emph{Intensity Dot Product Graphs} (IDPGs), which extend Random Dot Product Graphs by replacing a fixed collection of latent positions with a Poisson point process on a Euclidean latent space. This yields a model with random node populations, RDPG-style dot-product affinities, and a population-level intensity that links continuous latent structure to finite observed graphs. We define the heat map and the desire operator as continuous analogues of the probability matrix, prove a spectral consistency result connecting adjacency singular values to the operator spectrum, compare the construction with graphon and digraphon representations, and show how classical RDPGs arise in a concentrated limit. Because the model is parameterized by an evolving intensity, temporal extensions through partial differential equations arise naturally.

## 1. 核心问题与整体含义
*   **研究动机**：传统的隐位置随机图模型（如随机点积图 RDPG）将节点集视为固定，而基于图函数或随机测度的模型虽然允许节点随机出现，但牺牲了在显式欧几里得空间中的几何可解释性。在许多实际应用中（如生态群落、交通网络），交互实体的身份和数量本身就是随机的。
*   **核心目标**：提出一个统一的建模框架，既能保留 RDPG 模型中基于点积亲和力的直观几何解释，又能引入节点群体本身的随机性，并自然地连接连续隐结构与有限观测图。

## 2. 提出的方法论
*   **核心思想**：将 RDPG 中固定的隐位置集合替换为定义在乘积空间 `Ω = Bd+ × Bd+`（非负单位球）上的泊松点过程。该过程由一个**强度函数 ρ** 驱动，ρ(⃗g, ⃗r) 描述了具有特定“发出”倾向 (⃗g) 和“接收”倾向 (⃗r) 的个体在潜在空间中的期望密度。
*   **关键技术细节**：
    1.  **生成机制（实现规则）**：
        *   **持久规则 (R∞)**：从 PPP(ρ) 中采样长期存在的个体作为节点，所有有序节点对都有机会以概率 `K(s, t) = ⃗g_s · ⃗r_t` 形成连接。产生稠密图 (`O(N²)`边)。
        *   **瞬时规则 (R0)**：从 PPP(ρ) 中直接采样交互对（而非个体），每对内部的四个可能连接（两条交叉边、两条自环）独立生成。产生稀疏图 (`O(N)`边)，由不相交的小组件构成。
        *   **中间规则 (Rη)**：引入个体寿命概念，两个个体仅在寿命重叠时才能交互。通过重叠概率 `p_overlap` 在稠密与稀疏之间平滑插值。
    2.  **热图与期望算子**：
        *   **原始热密度** `h(s,t) = K(s,t)·ρ(s)·ρ(t)`，是概率矩阵的连续类比。其积分 `H(A,B)` 给出了从区域 A 到 B 的期望边数。
        *   当强度可分解为乘积形式 `ρ(⃗g, ⃗r)=ρ_G(⃗g)·ρ_R(⃗r)`时，可定义维数更低的**约束热图**。
        *   **期望算子 D̃**: `(D̃f)(g) = ∫ (g·r) f(r) ˜ρ_R(r) dr`，其中 ˜ρ_G, ˜ρ_R是归一化的边际强度。它捕捉了人均交互结构。
    3.  **谱一致性定理**：证明了在持久规则下，当总强度 Λ→∞时（即节点数 N→∞），观测图的邻接矩阵的缩放奇异值 `σ_k(A)/N`依概率收敛于期望算子 D̃的奇异值 `σ_k(D̃)`。
    4.  **与图函数的关系与区别**：
        *   证明了每个持久的 IDPG都可以表示为一个有向图函数（双线性形式），但这种表示必然破坏潜在空间的局部正则性（如Lipschitz连续性）。这是一个维度障碍：一维的标签空间无法忠实地表示高维几何。
    5.  **时序动力学扩展**：由于模型由连续强度函数 ρ参数化，其时间演化自然可以通过偏微分方程描述（如扩散、平流、追逃动力学）。这为建模网络结构的动态变化提供了数学工具。
