## 摘要
时序知识图谱（TKG）外推旨在基于历史事实预测未来事件。近期的研究尝试通过将 TKG 的演化结构表示和文本事件链集成到大语言模型（LLM）中来增强 TKG 外推。然而，这些方法受到两个主要挑战的限制：(1) 由于 TKG 的图演化结构表示与 LLM 的语义空间之间仅为浅层对齐，导致关键时空信息的丢失；(2) 在 LLM 微调过程中，TKG 的演化结构特征会逐渐稀释。为了应对这些挑战，我们提出了时空知识适配器（STK-Adapter），它灵活地集成了演化图编码器和 LLM，以促进 TKG 推理。在 STK-Adapter 中，设计了一个时空混合专家模型（Spatial-Temporal MoE）来捕捉 TKG 固有的空间结构和时间模式。采用事件感知混合专家模型（Event-Aware MoE）来建模事件链中复杂的时序语义依赖关系。此外，还提出了一种跨模态对齐混合专家模型（Cross-Modality Alignment MoE），通过 TKG 引导的注意力专家促进深层跨模态对齐。在基准数据集上的广泛实验表明，STK-Adapter 显著优于现有最先进的方法，并在跨数据集任务中表现出强大的泛化能力。代码可在 https://github.com/Zhaoshuyuan0246/STK-Adapter 获取。

## Abstract
Temporal Knowledge Graph (TKG) extrapolation aims to predict future events based on historical facts. Recent studies have attempted to enhance TKG extrapolation by integrating TKG's evolving structural representations and textual event chains into Large Language Models (LLMs). Yet, two main challenges limit these approaches: (1) The loss of essential spatial-temporal information due to shallow alignment between TKG's graph evolving structural representation and the LLM's semantic space, and (2) the progressive dilution of the TKG's evolving structural features during LLM fine-tuning. To address these challenges, we propose the Spatial-Temporal Knowledge Adapter (STK-Adapter), which flexibly integrates the evolving graph encoder and the LLM to facilitate TKG reasoning. In STK-Adapter, a Spatial-Temporal MoE is designed to capture spatial structures and temporal patterns inherent in TKGs. An Event-Aware MoE is employed to model intricate temporal semantics dependencies within event chains. In addition, a Cross-Modality Alignment MoE is proposed to facilitate deep cross-modality alignment by TKG-guided attention experts. Extensive experiments on benchmark datasets demonstrate that STK-Adapter significantly outperforms state-of-the-art methods and exhibits strong generalization capabilities in cross-dataset task. The code is available at https://github.com/Zhaoshuyuan0246/STK-Adapter.

### 2. 方法论：STK-Adapter
论文提出了一种**时空知识适配器（STK-Adapter）**，通过在 LLM 的每一层插入专门的混合专家（MoE）模块，实现图结构与文本语义的深度融合。

*   **核心思想**：建立专用的处理路径，在 LLM 的每一层动态注入和对齐 TKG 的演化结构表示与文本事件链。

    *   **时空混合专家（ST-MoE）**：利用预训练的演化图编码器提取实体和关系嵌入，通过稀疏激活的专家网络捕捉 TKG 中的空间结构和时间模式，并逐层传递以防止特征稀释。
    *   **事件感知混合专家（EA-MoE）**：针对文本化的事件链，设计了“事件感知路由”，确保属于同一事件的所有 Token 共享相同的路由信号，从而更好地建模事件间的时序依赖和重复模式。
    *   **跨模态对齐混合专家（CMA-MoE）**：采用 TKG 引导的注意力专家，将图表示作为 Key 和 Value，文本表示作为 Query，实现两种模态在语义空间上的深层对齐。
    *   **自适应融合（Adaptive Fusion）**：通过动态门控网络整合上述模块的输出，并与 LLM 原有的前馈网络（FFN）结合。
    *   **混合评分策略**：在推理阶段，结合 LLM 的解码概率得分与图编码器的拓扑得分进行最终排名。

### 7. 优点（亮点）
*   **架构创新**：将 MoE 引入 TKG 领域，并针对“事件”特性设计了专门的路由机制（EA-MoE），解决了 Token 级别处理破坏事件完整性的问题。
*   **即插即用**：模型对图编码器具有不可知性（Encoder-agnostic），可以灵活适配各种预训练的图模型。
*   **解决特征稀释**：通过逐层残差连接和专用路径，有效解决了长链推理中结构信息丢失的顽疾。

### 8. 不足与局限
*   **计算开销**：虽然推理速度有优化，但相比于纯嵌入模型，LLM 的引入和逐层 MoE 依然带来了显著的内存占用和计算延迟。
*   **依赖检索质量**：模型性能在很大程度上受限于时间逻辑规则（TLR）检索到的历史事件链的质量，若检索失效，性能会大幅下降。
*   **长序列限制**：受限于 LLM 的上下文窗口长度，对于历史极其冗长的查询，可能无法处理所有的相关背景。
