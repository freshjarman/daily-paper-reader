## 摘要
本文提出了一种利用自激励灵活残差点过程来预测限价订单簿持续期的方法。现代交易所中的高频事件呈现出厚尾的到达间隔时间，这对精确预测构成了重大挑战。所提出的方法结合了到达间隔时间的经验分布特征，同时保留了自激励和衰减结构。本研究还检验了该过程的随机稳定性，该过程可被解释为一个广义状态空间马尔可夫链。在适当条件下，该过程是不可约、非周期、正Harris常返的，并具有平稳分布。一项实证研究表明，在预测超高频交易数据中的持续期时，与几种替代方法相比，该模型取得了优异的预测性能。

## Abstract
This paper presents a method for forecasting limit order book durations using a self-exciting flexible residual point process. High-frequency events in modern exchanges exhibit heavy-tailed interarrival times, posing a significant challenge for accurate prediction. The proposed approach incorporates the empirical distributional features of interarrival times while preserving the self-exciting and decay structure. This work also examines the stochastic stability of the process, which can be interpreted as a general state-space Markov chain. Under suitable conditions, the process is irreducible, aperiodic, positive Harris recurrent, and has a stationary distribution. An empirical study demonstrates that the model achieves strong predictive performance compared with several alternative approaches when forecasting durations in ultra-high-frequency trading data.

## 2. 方法论
*   **核心思想**：构建一个统一的点过程框架，将观测到的到达间隔时间 `τ_n` 通过一个严格递增的变换函数 `Φ` 映射到一个独立的、同分布的创新序列 `ε_n` 上，即 `ε_n = Φ(τ_n, X_{n-1})`。其中 `X_{n-1}` 是一个依赖于历史信息的潜在状态变量。通过精心设计 `Φ` 和状态更新函数 `Ψ`，可以恢复出多种经典模型。
*   **关键技术细节 - SEFRPP模型**：
    *   **潜在状态演化 (Ψ)**：采用类似Hawkes过程的指数衰减形式：`Λ_n = μ + (Λ_{n-1} - μ + α) * exp(-β * τ_n)`。其中 `μ` 是基线强度，`α > 0` 是自激励跳跃幅度，`β > 0` 是衰减率。
    *   **变换函数 (Φ)**：定义为强度函数的积分：`Φ(t, Λ_{n-1}) = ∫_0^t Ψ(s, Λ_{n-1}) ds = μt + (Λ_{n-1} - μ + α) * (1 - exp(-βt)) / β`。
    *   **灵活残差**：创新项 `ε_n` 不再局限于标准指数分布，而是可以服从任何具有正支撑的连续分布（如Gamma、广义Gamma、Burr Type XII等），其均值被约束为1以便于识别。这使得条件强度函数变为：`λ_{n-1}(t) = h_ε(Φ(t, Λ_{n-1})) * Ψ(t, Λ_{n-1})`，其中 `h_ε` 是创新分布的风险函数。
    *   **稳定性条件**：为确保过程的平稳性（正Harris常返），需满足关键条件 `α < βμ_ε = β * E[ε] = β`。
*   **算法流程**：
    1.  给定参数 (`μ`, `α`, `β`, 残差分布参数) 和初始状态。
    2.  对于每个事件时间点 n：
        a.  根据当前潜在状态 `Λ_{n-1}` ，通过逆变换 `τ_n = Φ^{-1}(ε_n, Λ_{n-1})` （其中 ε_n i.i.d. ~ F_ε）生成下一个到达间隔时间。
        b.  使用更新规则更新潜在状态至 `Λ_n`.
    3.  参数估计采用最大似然估计法。
    4.  预测时，基于当前状态和估计参数，数值计算条件期望 `E[τ_{n+1} | F_n]`.
